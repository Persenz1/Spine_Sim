## 1. 审计范围与结论

本次审计覆盖 `钩爪式爬壁机器人抓附机理与多尺度力学模型.md` 以及 `逐篇文献机理卡/` 中的 18 份卡片，模式包括公式复算、量纲与正负号检查、跨章节符号一致性、来源冲突裁决、状态/约束闭合性和 Markdown 数学结构检查。

结论如下：

- 二维摩擦啮合、单刺梁强度、锥段危险截面、Hertz 接触、两刺与多刺弹性分载、失效后增量重分配、合力作用线、两爪/四爪偏载分配等核心闭式可回代原平衡式。
- 已修正会直接改变计算结果或使求解器欠闭合的问题，包括力作用点与搬移偶力混用、弧钩转角无条件取绝对值、三点球接触法向混用、硬限位无反力、滑移/限位误用粘着刚度、不同量纲裕量直接求最小值，以及位移零空间控制遗漏接触刚度。
- 18 份文献卡均被正文引用，引用文件无缺失；所有本稿公式编号唯一，交叉引用均能找到对应公式。

## 2. 关键公式复算

| 模块 | 复算对象 | 结果 | 结论 |
|---|---|---|---|
| 二维接触 | 将 \(N=T\sin\phi+P\cos\phi\)、\(F_\tau=T\cos\phi-P\sin\phi\) 回代两向平衡 | 两残差恒为零 | 通过 |
| 有限摩擦区 | 从 \(F_\tau\le\mu N\) 解 \(T/P\) | 得 \((\tan\phi+\mu)/(1-\mu\tan\phi)\) | 通过；分母非正时切换自锁分支 |
| 剥离楔紧 | 令 \(P=-Q\)，联合 \(N>0\) 与摩擦边界 | 得 \(T/Q\ge(\tan\phi+\mu)/(\mu\tan\phi-1)\) | 通过；仅绝对自锁几何有有限解 |
| 锥段强度 | 对 \(F_ry/[2\pi(d_m/2+by)^3]\) 求导 | 极值点 \(y=d_m/(4b)\)，峰值 \(8F_r/(27\pi b d_m^2)\) | 通过 |
| Hertz 反解 | 由 \(p_0=[6N(E^*)^2/(\pi^3R^{*2})]^{1/3}\) 与边缘拉应力反解 \(N\) | 系数为 \(9/2\) | 通过 |
| 两刺分载 | 将式 (8-10)–(8-12)回代 \(F=f_1+f_2\) | 残差恒为零 | 通过 |
| 有限加载刚度 | 失效前后平衡相减 | \(\Delta u=f_1^-/(k_L+k_2)\) | 通过 |
| 三维重分配 | 失效释放广义力与剩余/加载器切线平衡 | \((\mathbf K_L+\mathbf K_R)\Delta\mathbf q=\mathbf f_R^-\) | 通过；新增值域条件 |
| 合力作用线 | 验证 \([\mathbf F\times\mathbf M]/\|\mathbf F\|^2\) 的力臂矩 | 等于 \(\mathbf M_\perp\) | 通过 |
| 四爪偏载 | 对式 (11-11)分别求和及取 \(x,y\) 力矩 | 恢复 \(Z_\Sigma,M_x,M_y\) | 通过 |
| 混合搜索距离 | 对零点质量与指数尾积分、求期望 | 总概率 1，\(E[D]=(1-p_{0g})/\lambda_g\) | 通过 |

使用 10,000 组固定随机种子的浮点回代测试，未出现非零结构残差；按各自力、力矩或应力尺度归一化后，各项最大残差为 \(4.7\times10^{-12}\) 以下。

| ID | 位置 | 问题 | 采用方式 | 状态 |
|---|---|---|---|---|

| M-02 | 式 (3-15) | 用 \(\lvert C_\alpha\rvert\) 会把改善坡角的转动也判成旋脱 | 引入安装有符号映射 \(s_\alpha\) 和退化率 \(C_{deg}\) | 已闭环 |
| M-03 | 式 (3-22) | 原断裂应力式量纲错误，且遗漏裂纹几何因子 | 采用 \(K_{IIc}/(Y_{II}\sqrt{\pi c_f})\) | 公式已闭环；参数待识别 |
| M-04 | 式 (3-27) | 来源通道系数在摩擦锥边界不连续，且不保证属于 \([0,1]\) | 降为来源复现接口；通用模型改用显式针—管接触或试验标定 | 已隔离 |

8. 实际爪位姿、质心、载荷作用点和执行器限幅。
