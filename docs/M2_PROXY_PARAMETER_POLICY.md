# M2 无实测标定时的代理参数策略

## 适用范围

本策略用于 2026-07-28 持续恒载动力学修复后的 M2 第一轮。当前没有安装座质量、
阻尼、材料接触和摩擦实测标定，因此结果只在
`project_model_P_main_plane_dynamic_constant_preload_v2` 内用于相对筛选，不代表真实
墙面的绝对承载认证。

本轮实现版本为 `m2.2.0`；该版本同时修正刚性预载的摩擦分支顺序、轴向分段隐式
求解、正式 runner 的非必要逐对象内存跟踪，以及事件点过采样造成的统计偏差。
STICK/SLIDE 每步切换保留精确汇总计数，但完整路径点只按输出间距和主要事件保存。

## 中央代理参数

| 参数 | 中央值 | 依据 |
|---|---:|---|
| 针体密度 | 7850 kg/m³ | 钢材几何质量代理 |
| 轴向模态质量系数 | 1/3 | 均匀杆端位移 Ritz 质量 |
| 横向模态质量系数 | 0.236 | 均匀悬臂一阶模态代理 |
| 针体模态阻尼比 | 0.05 | 未标定结构阻尼中央代理 |
| 安装座等效质量 | 0.05 kg | 动态夹具中央代理 |
| 安装座竖向阻尼 | 1.0 N·s/m | 动态夹具中央代理 |
| 静/动摩擦系数 | 0.30/0.20 | 保守低摩擦基线代理 |
| 恢复系数 | 0 | 完全非弹性 Moreau 中央代理 |
| 屈服强度 | 800 MPa | 未冻结高碳钢的保守项目代理 |
| 内部时间步 | 1 ms | 地形尺度稳健指标的生产基线 |
| 初始预载求根容差 | 0.1 mN | 摩擦分支切换下的显式力容差 |

所有值逐 case 显式保存，不是隐藏默认值。

## 摩擦分层

在保持 60 个硬件构型、15 个配对 seed、100 mm 路径以及其他代理参数完全一致的
条件下，补充两个全量摩擦层：

| 分层 | 静摩擦系数 | 动摩擦系数 | case 数 |
|---|---:|---:|---:|
| 低 | 0.30 | 0.20 | 900 |
| 中 | 0.60 | 0.40 | 900 |
| 高 | 0.90 | 0.60 | 900 |

三个层级用于项目模型内的摩擦敏感性与排序稳定性比较，不表示墙面材料已经完成实测
标定。三组采用相同 seed 与构型顺序，可逐 case 配对分析。

## 杆体净空

正式 M1 二维表面可用于低成本后验检查。代理检查把圆柱杆体从针尖球心后退一个
杆半径处开始，沿针轴采样到安装座；它可以排除明显杆体碰撞，但不是锥段或杆体
分布接触求解。任何检测到负净空的 case 都不进入候选集。

## 解释边界

- 第一轮仍严格使用 15 个配对 seed、60 个硬件构型和完整 100 mm 路径。
- 低分位拉力、接触占空比、最大连续承载长度和结构/净空约束是主要指标。
- 1 ms 与 0.5 ms 的配对差异用于稳健性审计；冲击峰对步长更敏感，只作风险指标。
- 质量、阻尼、摩擦和恢复系数采用代表性扰动包络复核候选及对照构型。
- `formal_ranking_eligible` 继续保持 `false`，避免把代理模型排名误称为实验标定。
- 只有完成路径、数值收敛、屈服/屈曲/净空约束通过且敏感性结论稳定的构型，才可
  标记为 `project_model_robust_candidate`。
