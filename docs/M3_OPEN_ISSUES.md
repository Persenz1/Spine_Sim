# M3 共同背板阵列：审计问题与未闭合项

**状态日期：** 2026-07-29
**模块版本：** `m3.2.0`
**正式 campaign：** 未启动
**正式排名：** `formal_ranking_eligible=false`

本清单以“0.5/1/2 N 单元总预载，沉降后保持该总外载并沿 +x 拖拽
100 mm，用于比较构型拉力趋势”为当前需求。旧文档中的 fixture-only、
100 个贪心候选、M2 参数包绑定以及 50 mm 默认路径均不再是 M3 设计依据。

## 1. 已确认错误（本次已修正）

1. 沉降首步直接施加完整总预载，会人为制造启动冲击。现改为可审计的
   minimum-jerk 五次预载斜坡；沉降后完整总预载贯穿拖动阶段。
2. 沉降成功曾只检查低速和“存在接触”。现同时检查背板及全部针模态速度、总反力
   平衡误差、动力学残差、连续稳定步数和最大接近量。
3. 所有初始化失败曾归为 `initial_preload_infeasible`。现区分
   `physical_boundary`、`geometry_out_of_bounds`、`parameter_unclosed`、
   `settlement_nonconvergence` 和 `numerical_failure`，并保存具体失败码。
4. 初始化失败的承载统计曾以 0 或无穷大占位，可能进入排名。现失败 case 的条件
   性能字段为 null，`conditional_performance_available=false` 且
   `ranking_inclusion_allowed=false`。
5. 原结果只审计降采样保存点，内部坏步可能被漏掉。现每个拖动 proposal 都执行
   动力学残差门禁。
6. 自由针弹簧跨过分段/硬限位时曾用跨分支 Newton，可能收敛到错误分支。现逐分支
   求解并验证可行域。
7. `prepare_m3_round1_design.py` 曾依赖 fixture、`target_count=100` 和贪心下采样。
   现程序化生成 48 种基础硬件及全部阵列构型，不预绑定参数包。
8. 结果曾只有完整逐针时序。现提供 `summary`、`aggregate_trace` 和
   `full_pin_trace` 三档输出。
9. `COMPLETE` 曾只判断文件存在。现校验 `result.json` 内容哈希以及可选
   `path.npz` 哈希；写入仍采用临时文件替换的原子流程。

以下原有正确边界也已通过回归确认：M3 不调用 M2 静态二分预载根；背板和所有针在
同一状态向量中积分；所有针从同一旧状态形成 proposal；拒绝步骤不提交任何单针
历史；正序、逆序和固定随机遍历结果一致。

## 2. 高风险假设

1. 当前刚性 Moreau/Coulomb 接触仍是降阶模型。活动集、摩擦切换、同时冲击及再接触
   已有确定性夹具，但复杂粗糙面上的多接触解唯一性尚无独立证明。
2. 拖动内部残差门暂设为 1 mN，耦合投影松弛系数为 0.8，接触投影迭代数为 20。
   这些数值来自稳定性调试，不是物理标定。
3. 现有地形短程 smoke 中，6×6 最大动力学残差为
   \(8.41\times10^{-4}\) N，最大单步能量残差为
   \(1.97\times10^{-4}\) J。前者低于当前门值，后者仍需时间步和接触参数收敛研究；
   不能用“到达 path_end”代替能量闭合。
4. 冲击、非光滑投影造成的算法耗散尚未与物理阻尼/摩擦耗散完全分解。
5. 杆体净空目前是保存点上的圆柱杆代理后检查，不是杆体与二维/三维地形的分布式
   接触求解；锥段、支架和邻针干涉也未纳入动力学。
6. 全局耦合求解是密集小系统，对 120 万 case 的吞吐、内存和失败恢复尚未通过
   规模压测。分析脚本若直接读取所有逐 case JSON 也会成为瓶颈，应优先合并
   Parquet 分片。
7. 多 worker 首次为相同地形/y 轨迹写 M1 缓存可能竞争。正式运行前应串行预生成
   并冻结所需轨迹，campaign 只读消费 catalog/cache。

## 3. 尚未标定或未收敛

1. 背板质量、背板阻尼、针轴向/横向模态质量与阻尼。
2. 摩擦、恢复系数、材料屈服、屈曲和损伤参数。
3. 沉降专用阻尼倍数 10、预载斜坡时间 0.25 s、内部时间步、接触投影和残差阈值。
4. 100 mm 完整路径的时间步减半、接触参数、沉降阻尼敏感性。
5. 10 μm 初筛与同 realization 5 μm 细筛的一致性。
6. 砂纸、红砖、混凝土各 100 seed 的正式 M1 catalog 尚不存在；当前 45 个
   `defined_geometry` 条件只能做接口 smoke。
7. M1 后续更真实地形生成器的统计量、实测标定、跨分辨率 realization 身份和
   catalog 完整性。
8. 背板俯仰/横滚、翘曲、安装误差、局部 y 摩擦和损伤均不在当前模型自由度内。

上述任一项目未关闭时，结果都保持代理模型身份，正式排名门不得开启。
