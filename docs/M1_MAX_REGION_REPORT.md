# M1 最大需求区域报告

基准配方：

- 5 μm 规范网格、10 μm 生产网格；
- 相关长度 x/y 均为 50 μm；
- 高斯核截断 3 个相关长度。

设计空间由 `compute_campaign_region` 读取，不硬编码最终矩形。输入包括
100 mm 拖动、6×6、6 mm 间距、固定角/梯度角、4 mm 露出长度、4 mm 弹簧
行程、100 μm 针尖、梁位移、事件细化、杆体净空和随机核 halo。

计算结果：

| 项目 | 数值 |
|---|---:|
| 安装点跨度 x/y | 30 / 30 mm |
| 针尖水平投影范围 | 0.694593–3.305407 mm |
| x 总余量（每侧） | 7.671150 mm |
| y 总余量（每侧） | 5.100000 mm |
| 未对齐 x 边界 | -21.976558–125.976558 mm |
| 未对齐 y 边界 | -20.100000–20.100000 mm |
| 10 μm 外扩对齐区域 | 147.960 × 40.200 mm |
| shape | 4021 × 14797 |
| `float32` 高度 payload | 237,994,948 B |

x 余量分项为：针尖 0.1 mm、弹簧水平投影 2.571150 mm、梁 0.5 mm、
插值/事件 0.1 mm、杆体 4.25 mm、滤波 halo 0.15 mm。y 余量分项为：
针尖 0.1 mm、横向柔顺 0.5 mm、插值/事件 0.1 mm、杆体 4.25 mm、滤波
halo 0.15 mm。

区域覆盖测试确认：对齐后的下界不大于原始下界，上界不小于原始上界；
origin 落在 5 μm 偶数索引，所有设计输入和余量均出现在机器可读报告中。
