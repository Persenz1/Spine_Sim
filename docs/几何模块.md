# 几何模块

## 1. 模块作用

`src/spine_sim/geometry.py` 把 `TrackGeometry` 和一根刺的有序搜索路径转换成 `ContactCandidate`。

它负责：

- 候选搜索顺序；
- candidate identity 和 lineage；
- 有限针尖 support、gap 和三类法向；
- forward-cap 与杆体 clearance；
- 几何不确定性；
- 下一候选 continuation cursor。

它不计算接触力，也不决定候选是否稳定承载。

## 2. 输入对象

### `SurfaceState`

至少包含一个 `TrackGeometry`。做完整针体 clearance 时还需提供：

- `RegionSpec`；
- 原始 `height_m`；
- `source_valid_mask`。

构造时核对 region/track identity、高度内容 hash、mask 内容 hash、shape 和 dtype，防止用另一张表面的原始高度检查当前 track。

`surface_model` 固定为 `single_valued_height_field_2_5d`，一般 mesh scope 固定为 `OUT_OF_SCOPE`。

### `SpinePath`

保存：

- `path_position_m`：非空、单调非降；
- `sphere_centers_m`：每站球心；
- `track_indices`：每站对应的 track 节点。

`SpinePath.from_track` 可以直接从 track、球心 z 和可选节点子集建立路径。

### `SpinePose`

包含：

- `tip_axis`；
- `normal_model`；
- `gap_tolerance_m`；
- 可选球冠轴向长度；
- 可选锥段长度；
- 可选杆半径；
- 可选外露杆长；
- clearance 轴向/周向采样数。

提供的针体尺寸必须有限且为正；轴向采样数至少为 3，周向采样数至少为 8。只有四项完整针体尺寸都提供时，`has_complete_body_geometry=True`。

### `CandidateCursor`

不可变 continuation 状态：

- `next_path_index`；
- `candidate_index`；
- `last_feature_id`；
- `exhausted`。

拒绝候选时推进该刺 cursor，不影响其他刺。

## 3. 查询流程

入口：

```python
query_next_candidate(surface_state, spine_path, cursor, spine_pose)
```

流程：

1. 若 cursor 已耗尽，直接返回 `(None, cursor)`；
2. 从 `next_path_index` 开始按路径顺序扫描；
3. 球心 x/y 必须与被查询的 track 节点一致；
4. 计算
   \[
   g=z_{center}-H_R(x,y);
   \]
5. \(g>g_{tol}\) 时尚未闭合，继续扫描；
6. 读取当前节点的唯一或 top-2 support；
7. 跳过与 `last_feature_id` 相同的连续 feature；
8. 若 gap 在相邻站之间过零，只有两站及中间节点属于同一 feature 时才插值首次闭合位置；
9. 计算 forward-cap gate；
10. 若数据齐全，计算分段球冠—锥段—杆体 clearance；
11. 组装三类法向、切向基、gap 上下界和 uncertainty；
12. 生成 candidate ID、lineage 和下一 cursor。

支撑 identity 切换处禁止插值。否则会把两个不同表面 feature 人工混成一个接触点。

调用者需要完整遍历路径时，反复调用同一个查询接口直到 cursor 耗尽；不存在另一套搜索算法。

## 4. `ContactCandidate`

| 字段 | 含义 |
|---|---|
| `candidate_id` | 由 track、路径位置、针姿态和几何版本等生成的稳定 ID |
| `lineage` | 上游 track、高度、mask 和测量语义 lineage |
| `candidate_index` | 当前刺搜索过程中的候选序号 |
| `path_position_m` | 沿搜索路径首次遇到该 feature 的位置 |
| `feature_id` | 由 support 原始节点组成的 feature 身份 |
| `sphere_center_m` | 候选球心 |
| `support_points_m` | 一个或两个支撑点 |
| `signed_gap_m` | 球心与包络的有符号间隙 |
| `surface_normal` | 原始表面法向，可有多项 |
| `envelope_normal` | 唯一可微包络法向 |
| `contact_normal` | 球心—支撑径向法向，可有多项 |
| `normal_model` | 单刺本构请求使用的法向来源 |
| `tangent_basis` | 选定唯一法向存在时的局部切向基 |
| `valid` | track 有效、forward-cap 通过且没有确定杆体碰撞 |
| `near_tie` | top-1/top-2 支撑在容差内并列 |
| `geometry_uncertain` | 测量、mask、near-tie 或 clearance 未闭合造成的不确定性 |
| `gap_lower_m/gap_upper_m` | 可用时的间隙界 |
| `forward_cap_valid` | 支撑是否位于针尖可用球帽方向 |
| `rod_clearance` | 碰撞、最小间隙、采样数和警告 |
| `search_cursor` | 下一候选 continuation |

## 5. 法向选择

`selected_normal` 按 `normal_model` 选择 surface、envelope 或 contact normal。

唯一支撑候选的每个可用法向统一保存为 `(3,)`；near-tie 候选的 surface/contact normals 保存为 `(2,3)`，且 `envelope_normal=None`。

以下情况返回 `None`：

- `near_tie=True`；
- `normal_model="none"`；
- 请求的法向缺失。

法向的 shape 和有限性在 `ContactCandidate` 构造时统一校验；不合法候选会被直接拒绝，而不是由 `selected_normal` 再做一次容错。

几何层不会把两个可能接触法向平均成一个“确定法向”。单刺层看到 `None` 时返回模型未闭合或拒绝候选。

## 6. 有效性边界

`candidate.valid=True` 只说明几何层没有发现确定无效。它不代表：

- 已产生正法向反力；
- 静摩擦可行；
- 已稳定挂接；
- 材料容量闭合；
- 当前承担宏观载荷。

完整杆体尺寸缺失时，clearance 返回 unknown。原始高度缺失时，即使 track 存在也无法做姿态相关杆体检查。unknown 不能当作无碰撞。

## 7. 与单刺和阵列的接口

单刺接收一个 candidate，并使用：

- signed gap；
- `selected_normal`；
- sphere center 沿所选法向回退一个针尖半径得到接触点；
- valid/near-tie/forward-cap/rod-clearance gate；
- search cursor；
- 可选曲率半径。

当前正式候选的 `curvature_radius_m` 写为 `None`，所以依赖局部曲率的 Hertz/表面容量不会仅凭地形候选自动闭合。

阵列通过 `SpineInstance` 接收当前 candidate 和预先准备的 continuation candidates。阵列 Newton 迭代不会随背板位姿重新调用 `query_next_candidate`，因此几何搜索与阵列平衡是分开的接口，不是连续大转动接触追踪。

## 8. 当前边界

- 只支持 2.5D 高度场；
- 点云/mesh 在进入本模块前已栅格化；
- top-2 support 被保留，但主单刺仍是单点、单法向本构；
- tangent basis 目前不形成各向异性摩擦模型；
- 杆体 clearance 不产生接触力；
- candidate curvature 当前未从 track 估计；
- 接触点和法向不随阵列有限转角更新。

## 9. 对应机理

原始机理第 4 章对应本模块和 `terrain/envelope.py`：

- 二维/三维有限球尖可达包络：已实现高度场离散形式；
- 局部法向和多支撑：已实现三类法向及 near-tie；
- 首次遭遇距离：由 path position 和 cursor 表示；
- 三点球点云接触：未直接实现；
- 测量探针反卷积：未实现；
- 一般 SE(3) 配置空间：未实现。

## 10. 对应测试

`tests/test_geometry_contract.py` 覆盖：

- 候选顺序与 cursor；
- near-tie 不选择唯一法向；
- 禁止支撑插值；
- 同 feature gap 过零插值；
- feature switch 处分段；
- 原始高度/mask identity；
- gap bounds 和不完整杆体；
- 完整姿态 clearance；
- candidate identity 随姿态变化。
