## 2. 十种 M1 地形 smoke

命令：

```powershell
spine-m2 smoke-m1-suite
```

范围：

- 读取 M1 已保存的 10 个 50 μm 针尖 track；
- 每种地形只用一个确定性 smoke 起点；
- 若中心起点无法精确建立 0.5 N 预载，则按冻结的 track 分数序列
  `0.50, 0.60, 0.40, 0.70, 0.30, 0.55, 0.65, 0.80` 寻找首个可行 smoke 起点；
- 固定安装座 Z，拖动 1 mm；
- 普通步 50 μm，FREE 探测仍使用 10 μm track 分辨率；
- 单一测试构型：50 μm 针尖、0.8 mm 针径、70°、2000 N/m。

结果：10/10 建立目标预载、无数值不收敛并到达路径终点。该起点搜索只用于让
每种已有地形覆盖接口和状态字段，不是参数自适应筛选，也不构成成功率或排名。

所有随机地形结果仍为 `model_state=parameter_unclosed`，原因是当前 M1 track
不含二维杆体净空查询所需的原始表面接口。因此 `formal_ranking_eligible=false`。

机器可读报告：
`results/m2_validation/m1_ten_terrain_smoke.json`。

## 3. 解释边界

- 通过解析门禁是 M2 代码和项目降阶模型的验收证据，不是现实墙面绝对承载预测。
- 十地形 smoke 证明 M1→M2 数据、状态和输出字段可运行，不证明哪个半径、刚度、
  针径或角度更优。
- 正式随机粗筛仍受 `full_chain_frozen_manifest.json` 和用户批准门禁约束。
