# M2 未闭合问题

## 阻断正式排名

1. 安装座随 Z 运动的等效质量尚未由硬件冻结。
2. 针体动态降阶的模态质量、阻尼及其验证基线尚未冻结。
3. 针尖—砖/水泥表面的动态接触刚度、阻尼或恢复系数未标定。
4. 恒力执行器的带宽尚未冻结；首版只能声明“理想恒定外力”边界。
5. 杆体/锥段净空与分布接触未闭合。
6. 针体屈服、屈曲、疲劳和微损伤未实现。
7. 真实摩擦系数和速度依赖尚未标定。

## 已失效模型

`m2.0.0/project_model_P_main_plane_quasistatic_v1` 的 fixed-Z 路径以及 2026-07-28
前生成的 2700 个正式样式 case 全部标记为
`legacy_fixed_z_invalid_for_ranking`。其 `path_end`、有效承载比例、刚度/针径/摩擦
趋势不能用于硬件筛选。

- M1 有限球针尖包络和正式地形；
- 单针截面/静态梁柔度解析关系；
- M0 批处理、断点续跑和结果原子写入；
- 旧规定姿态核心作为迁移期静态夹具，但不能形成生产排名。
