# 空间杆接触模型与接口

Python 入口为 `spine_sim.ijms:run_case`。本页说明空间杆求解分支的力学模型、数值方法与数据接口。它不调用 `CondensedArray`；批量工具采用的平滑包络与增量摩擦过渡见[降阶接触模型](降阶接触模型.md)。

## 理论依据与适用范围

理论基础见[共同背板柔顺爪刺阵列：力学理论与推导](共同背板柔顺爪刺阵列：力学理论与推导.md)；跨尺度力传递关系见[钩爪式爬壁机器人抓附机理与多尺度力学模型](钩爪式爬壁机器人抓附机理与多尺度力学模型.md)。空间杆分支采用下述装配、加载和接触边界。

共同背板刚性、三个转角固定，X 位移控制，Z 平衡恒定总法向载荷，Y 默认自由且总侧向力为零，也可显式锁定。模型采用光滑固定轴导向、无预压的独立压缩弹簧、有限回缩行程、孔外不可伸长且无材料扭转的弹性变截面圆杆、圆钝球帽和固定表面；也支持根部固定的无弹簧安装。外部均布压力仅通过总载荷和装配参考点作用，逐刺载荷由求解获得。

单点接触模式在出现闭合多支撑时停止并报告模型范围限制；显式启用多点接触模式时，逐个支撑求解接触与摩擦。杆体与墙面碰撞及弹性许用值到界均停止路径并记录原因。它们不会被当成刺断裂或删除。没有真实动力回弹、材料破坏、墙面损伤、导向摩擦、针与针互碰、柔性背板或整机模型。三维高度场不能表示倒扣表面。

## 坐标与装配

背板实际平移为 `q=(X,Y,Z)`，+X 为拖动、+Z 为离墙方向。壁面对第 i 根针的力为 `f_i`：

\[
T=-\sum_i f_{ix},\quad P=\sum_i f_{iz},\quad L=\sum_i f_{iy},\quad N_i=f_i\cdot n_i.
\]

P_i 是宏观法向分量，N_i 是局部接触法向力，两者分别输出。T 可以为负。预载时斜针会产生切向反力，拖动时可能释放弹性能，均不截零。

`theta_deg` 是导向轴向下倾角；`yaw_deg=0` 时 `a=(cosθ,0,−sinθ)`。初始最外球面端点共面，`O_i^0=(x_i,y_i,r_i)`，`G_i=O_i^0−l0_i a_i`，实际导口是 `G_i+q`。网格间距指未变形针尖位置，不是导口间距。逐刺角度、长度、刚度、行程、直径和球半径均可覆盖。

`common_mouth_height_m=H` 改用共同导口高度装配，长度由 `(H−r_i)/sinθ_i` 求得，此时应省略显式 `free_length_m`。显式angle_gradient_deg={toe:60,heel:80}与heel_free_length_m=.004采用爪跟基准：H=rheel+lheel sinθheel，其余长度按共同H补偿；不得同时指定theta_deg或common_mouth_height_m。uniform组直接使用free_length_m=.004，不随角度改变。`loaded_area_m2` 是真实受压面积，不能仅凭零宽度的一行针推定。

## 可回缩空间杆

`guided_rod.GuidedRod` 的状态是 `[s/l0, β1,γ1,…,βm,γm]`。导口切线固定，后续节点有两个弯曲坐标。相邻单位切线以大圆弧连接，杆中心线由圆弧段组成，段长随l=l0−s更新。taper_length_m>0时按归一化边界1−(1−j/m)²在尖端加密；各段中心线积分准确，EI按所覆盖材料区间积分。段数控制连续杆近似误差。

`ijms.build_rods` 还支持 `rod_reduction="force_moment_ritz"`，此时构造 `ModalGuidedRod`，通过端力／端矩形函数参数化杆的角度场，保留离散杆的几何与积分。其平衡残差属于投影后的自由度，不能解释为完整逐段自由度的离散误差。`rod_reduction="none"` 使用 `GuidedRod`。

\[
U=\tfrac12 k_s s^2 + \sum_j \frac{\alpha_j^2}{2h_j^2}\int_{u_{j+1}}^{u_j} E I(u)\,du.
\]

其中u由球心朝根部量取，a(u)=r+(D/2−r)min(u/Lt,1)，I(u)=πa(u)^4/4。taper_length_m=0对应等径杆分支。这里α_j为相邻单位切线夹角。端坐标、末端转动和能量来自同一构型；压缩导数含弯曲能随长度变化的项，保留移动边界配置力。仅更新 `3EI/(l0−s)^3` 不能代替变长度能量的一致导数。

球面力在球心的力偶为 `τ=−r n×f`。广义平衡为

\[
R=U_u-J_O^T f-J_\omega^T\tau=0.
\]

端截面采用无材料扭转的平行搬运。针端可随弯曲转动，导口姿态始终固定。压缩方向导数解析计算，角度和切线使用批量化的相同中心差分；逐段旋转次序和步长不变。杆段数由离散配置指定；非线性接触路径的离散误差需结合代表工况的加密结果判断。

上限位 `s=smax` 通过互补条件承担额外压缩反力，不采用惩罚大刚度，也不冻结弯曲自由度。默认 `lower_stop=false` 时，零压缩处仍要求轴向广义平衡，不能借下界承担拉力。只有显式 `lower_stop=true` 才允许伸出端挡肩反力。额定smax允许为4 mm且达到/超过l0，此时有效物理域仍要求l>0；在接触容差分辨率内完全缩回返回EXPOSED_LENGTH_LIMIT而不接受该状态，不能借此承担硬限位反力。截面按当前露出材料计算，理想导向不模拟孔内配合。mount_type='fixed'严格约束s=0，不含弹簧能量；真实根部反力与虚拟轴向残量分别输出。

应力用当前实际中心线、球面力偶及沿杆位置到受力点的力臂计算，包含轴向、弯曲、横剪和扭矩的圆截面保守等效应力。空间最大值在采样截面上评估；杆段和应力采样误差需通过代表工况加密检查。缺少 `allowable_stress_Pa` 时只给应力，不伪造利用率或材料容量。

## 接触与路径

`continuous_geometry` 接受真实三维球心，返回连续三角高度场或无限平面的最近支撑点、物理单位法向和法向间隙 `g=有符号欧氏距离−r`。X/Y 查询位置连续，不受高度网格节点限制。三角网格缝的共面重复支撑被合并；真正近并列支撑保留；闭合后的处理由单点或多点接触模式决定。

接触满足 `g≥0, N≥0, gN=0`。三维切向力通过库仑圆盘投影联立求解。材料点切向增量采用

\[
\Delta u_t=\Pi_t\{\Delta O+\log(R_{new}R_{old}^T)\times[-r\bar n]\}.
\]

它包含针端转动，不等于球心位移或墙面接触点位移。该式是有限步长离散，误差通过拖动步长细化控制。接触特征 ID 用于几何延续，不承担摩擦零位；已接受的杆构型、球心、端转动和力共同保存历史。持续滑动延续动摩擦支路，滑移停止后才允许恢复静摩擦支路。

流程是竖直接近至最早零力接触、递增建立目标 P、从完整预载状态开始拖动。外层控制物理路径和接受状态，内层稀疏最小二乘只求同一站的增广平衡。任何 Newton 中间值都不记为物理状态。

模式转换和明显的几何特征切换会缩步定位，再从前一已接受状态求有限重平衡。X/Y/Z 与杆内变量共同参与，逐刺力不预分配。初始等分载荷仅作为非线性求解器初值。

球心构型段进行扫掠胶囊检查，超过几何容差的中途阻挡要求缩步，不能从可行端点直接穿过凸峰。渐细曲杆由真实法截面圆盘检查：平面用解析支撑，高度场求圆盘与三角片投影相交区域的最小法向高度差，轴向细分用明确的包络误差界。不能判明时返回ROD_GEOMETRY_UNRESOLVED，不以最大杆径胶囊冒充实际尖端。等径杆分支采用胶囊检查。圆钝帽只允许末端切线前半球承载，背面接触为TIP_CONTACT_DOMAIN。该做法验证离散构型段的几何可达性，不把它解释为真实动态回弹轨迹。最小步长下仍不能继续时保留已完成前缀，报告具体限制或数值失败。

## 全局求解与稳定性

每刺有局部杆变量及三个力变量，共同未知量只有 Y/Z（Y 锁定时只有 Z）。内变量保留于增广系统，有限差分按局部列分组，矩阵连接局部块与共同平衡行。单点分支对活动杆缩减系统按未知量数选择线性子问题：不超过 1024 个时使用直接信赖域求解，超过时使用稀疏 LSMR，方程和物理残差容差相同。默认在CPU执行，可通过 runner 按 case 多进程并行。

`guided_stability.assess_stick_stability` 对光滑严格粘着支路在固定 X/转角下检查内部杆模态和允许 Y/Z 模态。它对含实际法向变化、预载及变长度的虚功残量求导，施加接触/限位约束，再逐刺凝聚。输出局部约束增量能量判据及矩阵不对称程度。滑动、摩擦边界、接触边界和不光滑几何单独报告，不能据此保证动态稳定。负的拖动力斜率不是本程序的失稳判据。

默认只在最后已接受状态做这项成本较高的检查；`solver.stability="off"` 可关闭，结果将明确标为未检查。逐站稳定性研究可直接调用该 Python 接口。

`single_spine.py`、`array.py` 和 `canonical_module.py` 提供独立的解析对照模型，空间杆分支不隐式调用这些求解器。版本字段和结果身份用于区分不同模型。

## 状态续算与实验接口

`output.level="full"` 的摘要包含 `continuation_state`。用 `PathState.from_snapshot(summary["continuation_state"])` 恢复完整材料运动历史，在相同装配、表面和机理版本的 `GuidedArray` 上调用 `solve(previous, x_m, preload_N)`，可以继续拖动或固定当前 X 求保持平衡。保持与方向加载计算可复用此状态；JSON 协议只定义预载和沿 +X 拖动，一般方向加载需通过 Python 接口显式指定控制规则。runner 的 `resume` 是按 case 恢复，不能替代此内部状态续算接口。

`research_protocols.SensorCalibration` 提供坐标旋转、力矩参考点移动、去皮和位移/时间零点映射。实测刚度、许用应力和摩擦可直接进入逐刺参数；导向摩擦与间隙只能先记录和标定，不能冒充理想导向模型已包含这些效应。

## 输出与数值检查

摘要在精简轨迹前保存 `window_metrics`、`establishments`、距离加权的 `path_statistics` 和 `preload_state`。表面来源元数据随高度场传入；名义弹簧行程与正露出长度的几何范围分别检查。运行方式见[项目说明](../README.md)。

数值检查包括变截面能量导数与柔度、圆截面碰撞、路径中段障碍、固定与弹簧安装边界、装配相容、状态续算和参数配对。内部函数计时与短路径算例不能代替完整批次的耗时或精度评估。

## 同针多点接触

`solver.multipoint_contact=true` 允许切换到同一针尖的多支撑求解器。`GuidedArray.solve` 根据接触历史、近并列支撑与特征变化决定是否调用 `multipoint_contact.solve_multicontact`；单点试算出现多点范围限制或数值失败时，启用多点模式也可触发该求解器；单点分支的 `friction_solver` 则独立选择 `projection` 或 `active_set`。
每根杆及其弹簧仍只有一套内部变量；逐点接触力与`-r n×f`球心力矩求和后进入原杆的虚功方程。
各点使用真实法向、实际材料点运动与原静/动库仑条件，不平均法向，不复制弹簧。
静摩擦分载可能不唯一，先寻找同时满足各点摩擦锥的平衡，再判断是否需要滑动。
接触切换可释放原支撑，也可在新支撑处重新粘着；不将该过程默认当成断裂或动态回弹。

完整输出的`per_spine[].contacts`保存逐点力、法向、间隙、材料点位移和状态；
`continuation_state.contact_history`保存逐点历史。`forces_N`仍为每根针的合力，
`N_N`及局部法向分载统计使用各支撑法向压力之和，`P_N`仍为合力的Z分量。
求解语义版本为`guided-rod-incremental-contact-3`；旧版本记录应保留，不与新批次混用。
稳定性接口不支持多点粘着支路的判定，该情况报告未实现。设置 `stability="off"` 可关闭稳定性检查，输出保留未检查状态。
针帽范围、杆体碰撞、弹性和露出长度限制同样适用于多点接触；恒预载拖动过程中总 P 持续施加。
