# IJMS 阵列扫描规划

当前交付为0.6.0：变截面针、固定安装、梯度长度补偿及小阵列粗筛入口已实现。**实际小阵列输入以 [ijms_small_array.json](../experiments/ijms_small_array.json) 为准**，使用方法见 [小阵列启动](IJMS小阵列启动.md)。[ijms_scan_plan.json](../experiments/ijms_scan_plan.json) 描述科学范围，不是可直接传给通用runner的CampaignSpec。

## 1. 固定针形与安装

- 圆钝尖半径50/100 μm；主体直径1 mm；线性渐细段2 mm。球帽采用前半球，背面被渐细杆遮挡。
- 材料坐标u由尖端等效球心朝根部量起。u≤2 mm时a(u)=r+(0.5 mm−r)u/(2 mm)，之后a=0.5 mm。局部A=πa²、I=πa⁴/4。
- 均匀角阵列的无载露出l0=4 mm，不随角度变化；长度沿用导口至等效球心的中心线定义，包含2 mm渐细段。
- 梯度角组为前排爪头60°、后排爪跟80°，中间排线性分配。以爪跟l0=4 mm确定H=rheel+4 mm·sin80°，其他li=(H−ri)/sinθi；相同r时爪头约4.55 mm，补偿主体长度，渐细段不变。
- 固定安装只建模露出段，根部位置和切线固定，s=0，无弹簧能量，仍计算针杆弯曲。它不是k=0自由滑针或任意大k近似。
- 弹簧额定行程固定4 mm。回缩裁去靠根部的露出材料，渐细轮廓不被拉伸；理想固定切线导向仍作用于当前导口截面，不模拟孔内接触或配合间隙。
- 实际露出长度必须l=l0−s>0。额定行程达到或超过l0时，完全缩回是EXPOSED_LENGTH_LIMIT，不是能承额外反力的硬限位，也不允许零/负长度。数值分辨率内抵达此边界就保留前缀并停止，不把4 mm额定行程改小。
- EI按实际材料截面积分，压缩导数含变长度配置力，局部应力用同一A/I。不能把针尖半径当整根杆半径，也不能把全针按1 mm粗杆计算。

主体直径、渐细段和长度规则不参与本轮优化。同刺数转向解释布置方向；不同针数比较同时保留N与占地。当前loaded_area_m2采用每针一个间距单元的名义面积，用于尺寸记录；本批只施加总P，不据此冒充已测实体压强。

主表：4×4、间距5 mm，2半径×(4均匀角+1梯度角)×(6刚度+固定安装)=70个设计。
布置表：2半径×[固定安装、ks100/800/5000]，均匀70°，交叉12布置和3间距，共288个。与主表重复8个，去重为**350个设计**。

## 3. 材料主表与执行顺序

5个条件：混凝土rough_wall、红砖fired_brick_standard、砂纸P40/P100/P240。
每个条件64个合成实现、每设计3个P，共 **350×3×5×64=336000条小阵列粗筛路径**。seed固定从2026091000开始；各设计和P共享该材料/seed的同一原始墙面与固定落点，不重新随机。

先执行首个seed上的8个预定参考设计（两个半径各配固定安装与软/中/硬弹簧）的3个P，按材料轮转，合计120个full输出。其余summary；1605个分片，每片最多256case。只是改变执行顺序，不减少样本或降低保真度。

第一晚用于启动该队列、检查既定代表与记录实际吞吐；336000条不承诺一晚完成。执行模型可等价优化代码、调worker和分片恢复，不按运行结果自行筛掉设计、换表面或开始细筛。

## 4. 地形与实验的对应

材料形貌保留应用主线，受控随机形貌解释原因，实体砂纸连接实验。混凝土与红砖profile是工程先验；砂纸三档有公开实测形貌依据，但合成seed不增加实测样片数。

本地data/raw/mendeley_hcgcnm269w_v2/含P40/P100/P240各一张Hirox扫描，横向采样1.08954 μm，大小约10×1 mm。它们短边不足以直接覆盖阵列。大场明确采用synthetic模式：实测patch拼接、有限残差、分位数匹配，并保留实际生成方法与来源。公开扫描与未来购买试样不是同一块墙面。[公开数据集](https://data.mendeley.com/datasets/hcgcnm269w/2)

正式批次按需生成并只读复用材料高度，不先造完整320张。最大初始中心跨度42 mm，单边8 mm几何/运动裕量，+X另加10 mm行程，域约68×58 mm，origin=(-29,-29) mm。10 μm网格float64高度约316 MB/张，整库约101 GB，仅指高度数据。有限域外如实停止，不锁Y、不抽新落点。多进程可共享同一NPY只读映射；样本/材料切换后worker缓存相应更新。

当前材料字段、实际模式、probe/测量说明随metadata_path传入结果。坡度、曲率和拼接特征应按实际形貌解释；砂纸粒度不是只改变RMS的数学单因素实验。砂纸实体宜固定材料/装夹/方向，红砖和混凝土可做跨材料验证；没有逐项实测不阻止本批按既定情景运行。

## 5. 指标与数值设置

绝对承载目标0.5/1/2 N，归一化目标T/P≥1；保持0.5 mm，搜索窗口2/5/10 mm，共12协议。完整保持窗必须在搜索上限内结束；未完成路径保持未知，不删样本、不补零。原0.2 N不再作为主筛选标准：在当前P与μk下平面摩擦就可能通过它。

摘要同时保留窗口J+/J−/Jnet、T统计与建立状态，预载初态、路径长度加权的参与/分载、回缩/储能/触限/应力，以及事件、范围终止和数值失败。固定根部真实反力为−f；虚拟回缩残量含配置力，另列，不能与实测根部轴向力混用。稳定性在本批明确设off，不把COMPLETED当稳定性证明。

针杆16段、靠尖端加密；表面10 μm；最大拖动步长2.5 μm，事件继续细分；归一化残差2e−6、接触容差2 nm、max_nfev200、最多20000站点。16段的一个连续小变形柔度参照误差约1.49%（8段约5.34%）；这支持当前段数选择，不宣称所有非线性/接触场景已收敛。粗细筛不能为省时暗降精度。

以同P的持续承载、效率和分载比较，不把一个绝对阈值独立作为几何啮合证明。材料分开报告；若科研定稿需要聚合，混凝土/红砖/砂纸各1/3，砂纸内部三档等权。

## 6. 后续细筛、机制组与大阵列

本次启动只执行已交付小阵列材料粗筛。后续细筛可采用每条件256个新实现、冻结确认每条件1024个新实现；候选ID和具体细化点需由科研阶段根据粗筛结果写定，DeepSeek不自行选论文赢家。

受控机制组保留12类设想：相同幅值变尺度3类、相同尺度变幅值2类、各向异性方向3类、富峰/富坑2类、长短尺度主导2类。它们用于解释材料组中的机制，尚未编译到本次overnight队列，不将缺少该组视为编码故障。
具体参考为：RMS60 μm与尺度120/480/1920 μm；尺度480 μm与RMS15/240 μm；尺度比4方向0/45/90°；g+0.35(g²−1)及其负场归一RMS60 μm；120/1920 μm双尺度短分量方差份额.25/.75。相关长度以生成器定义和成品统计分别说明。

大阵列只在小阵列后制定；候选8×8、10×10、15×15、20×20、30×30，总P上限10 N。保留.5/1/2 N公共档，额外4/6/8/10 N仅为待选择候选。固定P、名义P/N、固定间距扩面积和固定面积加密分别研究，实际每针分载始终联立求解。当前模型无针间碰撞，密集方案必须按此范围解释。新大墙面同时补跑小阵列参照，不靠改变FFT尺寸后重复seed假装同一物理表面。
