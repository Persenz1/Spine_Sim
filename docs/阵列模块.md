# 阵列模块

## 1. 模块作用

`src/spine_sim/array.py` 在刚性共同背板上组合任意数量的单刺，求六自由度混合控制下的准静态平衡、活动接触、事件级联和稳定性。

阵列只调用 `solve_single_spine`，不复制第二套局部摩擦、弹簧或容量模型。

`src/spine_sim/metrics.py` 提供与阵列配套的公共计数和路径指标，放在本文件末尾说明；这里描述实现，不分析任何具体仿真结果。

## 2. 输入对象

### `SpineInstance`

每根刺包含：

- `SpineGeometry`；
- `SpineMaterial`；
- `FrictionParameters`；
- `SuspensionParameters`；
- `SingleSpineTolerances`；
- 非负装配初始间隙 `initial_gap_m`；
- 当前 `candidate`；
- 可选 `continuation_candidates`；
- `stable_engagement: bool | None`；
- 搜索距离增量。

`candidate` 与 continuation 序列直接使用 `ContactCandidate`；候选 ID 必须唯一，candidate index 必须递增，搜索位置使用 `CandidateCursor`。承载状态引用的 candidate ID 若不在该实例候选序列中，属于数据完整性错误。

### `ArrayAcceptedState`

保存：

- 六维 `q_C`；
- 与输入刺顺序一致的逐刺 accepted state；
- 载荷参数；
- revision。

构造边界要求 `q_C` 是有限六维向量、逐刺状态非空且 ID 唯一、载荷参数有限、revision 为非负整数。与 `SpineInstance` 序列之间的数量、ID 和顺序一致性在主求解入口检查。

### `MixedControl`

六个广义分量按三平移、三转动排列。每个分量必须且只能使用：

- `PRESCRIBED_POSE`；或
- `REQUIRED_WRENCH`。

同一分量不能同时给 pose 和 wrench。

其他字段：

- 对称半正定 `loader_stiffness`；
- `initial_q_C`、`q_rate_C`；
- 参考力 `F_ref_N`、参考长度 `L_ref_m`；
- frame、参考点、参考位置和背板对象；
- 抗拖方向；
- 可选齐次约束矩阵。

## 3. `q_C` 和物理位姿

`q_C` 是接触约束相对背板的加载广义坐标。固定墙面时：

\[
\mathbf q_{backplate}^{phys}=-\mathbf q_C.
\]

结果同时保存 `q_C` 和 `physical_backplate_pose`，两者符号相反。

## 4. 初始间隙和地形间隙

装配初始间隙与地形 signed gap 是两个独立量：

\[
d_i=d_i^0+g_{i,terrain}.
\]

第 \(i\) 根刺接触点的小位移映射：

\[
\mathbf B_i=
\left[\mathbf I,-[\mathbf r_i-\mathbf r_0]_\times\right].
\]

单刺相对加载位移：

\[
\mathbf u_i=\mathbf B_i\mathbf q_C-d_i\mathbf n_i.
\]

尚未闭合时的剩余间隙：

\[
g_i=\max(d_i-\mathbf n_i^T\mathbf B_i\mathbf q_C,0).
\]

闭合后的过闭合进入单刺弹性位移，不再以负几何 gap 传给单刺 solver。

## 5. 阵列装配

每根刺调用 canonical 单刺求解器，然后把根部力搬移到阵列参考点：

\[
\mathbf W_R=\sum_i\mathbf W_i,
\]

\[
\mathbf K_R=\sum_i\mathbf B_i^T\mathbf K_i\mathbf B_i.
\]

逐刺装配为 \(O(N)\)。全局稠密矩阵始终为 6×6，不构造 N×N 逐刺耦合矩阵。

## 6. 平衡方程

required-wrench 自由分量上的残差：

\[
\mathbf R=
\mathbf W_R+\mathbf K_L\mathbf q_C-\mathbf W_{req}=0.
\]

尺度化规则：

- 力残差除以 \(F_{ref}\)；
- 力矩残差除以 \(F_{ref}L_{ref}\)；
- 平移坐标用 \(L_{ref}\) 缩放；
- 转动坐标保持 rad。

rank、range compatibility、残差和稳定性都在尺度化系统中计算。

## 7. 主求解流程

入口：

```python
solve_array_equilibrium(...) -> ArrayTrial
```

流程：

1. 核对刺 ID、顺序、accepted state、load parameter 和控制合同；
2. 从 accepted/initial `q_C` 开始，满足 prescribed pose 和齐次约束；
3. 调用每根刺的 `solve_single_spine`，装配总 wrench 和 tangent；
4. 在 admissible free subspace 求尺度化 Newton 修正；
5. 若当前接触集缺秩，尝试从开放候选中选择与 required wrench 方向相容的接触 seed；
6. 检查逐刺 trial 中的物理事件；
7. 只推进全阵列最早事件，并在同一载荷重新装配；
8. 永久断开时记录释放 wrench 并预测事件后重平衡；
9. 非永久容量边界时，把所有刺重新计算到同一个全局最早边界，返回 `MODEL_LIMIT`；
10. 收敛后分别评估 rank、range、equilibrium、quasistatic stability、model 和 numerical state；
11. 所有条件满足才生成可提交 proposed state。

同一载荷下的事件按全局 `q_C` 位置排序，不直接比较各刺局部 event fraction。

## 8. 接触 seed

在 force-controlled 自由分量下，初始全部开口会产生没有支撑刚度的缺秩系统。求解器可以：

1. 从当前开放且可用的候选中建立闭合预测；
2. 在齐次约束自由子空间内检查该候选能否产生所需 wrench 方向；
3. 选择一个未尝试的候选作为接触 seed；
4. 重新装配正式单刺本构。

seed 只生成接触起始状态，不绕过单刺摩擦、容量和事件检查。

## 9. 事件级联和重平衡

阵列先选择本轮最早事件。命中事件的刺把 working state 更新为该 trial 的 proposed state，并把各自的 working reference 沿当前 `q_C` 方向推进到事件分数；未命中的刺保留原 working state/reference。随后程序仍在当前 `q_C` 重新装配并求平衡。`MODEL_LIMIT` 是例外：全阵列会在选定边界位姿重新装配后停止。

永久断开释放的广义力为 \(\mathbf W_{released}\)，预测修正满足：

\[
(\mathbf K_L+\mathbf K_R)\Delta\mathbf q_C
=\mathbf W_{released}.
\]

该式只提供事件后初始猜测。随后仍调用正式装配和求解检查残差、活动集和下一个事件。

`STOP_MODEL_LIMIT` 类型的容量边界不会把刺删除后继续外推，而是返回不可提交的模型边界。

## 10. 平衡状态

| `EquilibriumStatus` | 含义 |
|---|---|
| `SOLVED` | 残差收敛并满足 rank/range 合同 |
| `RANK_DEFICIENT` | admissible system 缺秩 |
| `RANGE_INCOMPATIBLE` | required wrench 不在当前系统值域 |
| `NONCONVERGED` | 全局平衡迭代未收敛 |
| `MODEL_LIMIT` | 到达不能继续演化的物理模型边界 |

另外分别保存：

- `RankStatus`：full rank / rank deficient；
- `RangeStatus`：compatible / incompatible；
- `NumericalState`：由各局部单刺 trial 的数值状态和可提交性汇总；它与 `EquilibriumStatus` 独立，因此全局可为 `SOLVED` 而整体 numerical state 仍为 `NONCONVERGED`；
- `ModelState`：closed / parameter unclosed / out of scope。

这些字段不能合并成一个 success 标记。

## 11. 保守稳定性

对全 STICK，或 HARDSTOP 内保存 STICK 子模态的保守分支，构造：

\[
\hat{\mathbf K}=
\frac{\mathbf D_q^T\mathbf K_T\mathbf D_q}
{F_{ref}L_{ref}},
\]

再投影到满足 active equality 的自由子空间：

\[
\mathbf K_{red}=
\mathbf Z^T\operatorname{sym}(\hat{\mathbf K})\mathbf Z.
\]

根据最小特征值和容差分类：

- `STABLE_CONSERVATIVE`；
- `MARGINAL_CONSERVATIVE`；
- `UNSTABLE_CONSERVATIVE`；
- `NO_FREE_MODE`。

## 12. 滑移分支

SLIP 或非对称切线不能用对称刚度正定解释为动态稳定。

SLIP 或非对称切线分支只在全局平衡已解且所有局部 trial 已由单刺数值边界判为可提交时评估。阵列层不重复逐项检查单刺互补残差，只增加阵列独有的滑移耗散条件：滑移摩擦力相对速度的功率不得为正。满足时返回：

```text
DIRECTIONALLY_ADMISSIBLE_QUASISTATIC
```

所有当前阵列结果的 `dynamic_stability` 都是 `OUT_OF_SCOPE`。

## 13. 输出

`ArrayResult` 保存：

- `q_C` 和 `physical_backplate_pose`；
- 总 wrench 和总 tangent；
- 逐刺 gap、加载位移、广义 wrench 和单刺 result；
- 公共计数；
- rank/range/equilibrium/stability/model/numerical 状态；
- 迭代、奇异值、残差和稳定特征值 diagnostics；
- events；
- released wrenches；
- rebalance predictions；
- assumptions 和 omissions。

trial 只有在 equilibrium 为 `SOLVED`、稳定性可接受、所有局部 trial 可提交且没有 model limit 时才可提交。

## 14. Trial 与 commit

`ArrayTrial` 保存 base revision、proposed state、result 和 `committable`。

`commit_array_trial` 要求 base revision 等于当前 accepted revision，且 trial 已完成可容许平衡。否则 accepted state 不变。

## 15. 公共计数

`compute_array_counts` 区分：

- `n_nominal`：名义安装数；
- `n_geometric`：有效几何候选数；
- `n_contact`：`geometric=True` 且有限 `signed_gap_m <= gap_tolerance_m` 的项目数；该计数不检查正法向力或承载状态；
- `n_evaluable`：stable engagement 可判断数；
- `n_engaged`：全部可判断时的稳定挂接数；
- `n_engaged_lower/upper`：存在 unknown 时的上下界；
- `n_active`：当前实际承载数。

unknown engagement 不会被强制当作 false。

法向和正向切向的有效分担根数使用 inverse Simpson：

\[
n_{share}=\frac{(\sum_i p_i)^2}{\sum_i p_i^2}.
\]

`load_sharing_index` 只对 active 刺计算最大载荷幅值与平均载荷幅值之比。

## 16. 路径指标实现

`integrate_path_resistance` 只在相邻两站同时 accepted、valid 且力有限时做梯形积分。无效站不补零，也不跨缺口连接。

令 \(f(s)=F_R(s)/P_{ext}\)：

\[
J^+=\frac{1}{L_{eff}}\int\max(f,0)\,ds,
\]

\[
J^-=\frac{1}{L_{eff}}\int\max(-f,0)\,ds,
\qquad
J_{net}=J^+-J^-.
\]

该函数只定义数据计算方法。阵列 solver 不自动运行完整路径，也不自动调用这一指标。

## 17. 当前边界

- 刚性共同背板；
- 小位移固定接触点映射，不更新有限转角；
- candidate 在阵列外预先构造，不在 Newton 迭代中重新查地形；
- `stable_engagement` 是输入，不由阵列自动推断；
- 不含背板连续弯曲和刺间实体接触；
- 不含质量、阻尼、冲击和动态稳定；
- 不含整爪、腕部和整机平衡；
- 缺少的几何刚度会记录在 omissions；
- 大 N 装配的 6×6 结构不等于完整真实 campaign 的性能保证。

## 18. 对应机理与测试

对应原始机理：

- 第 8 章：两刺分载基线；
- 第 9 章：n 刺共同背板与事件后重平衡；
- 第 10 章：逐刺力向参考点合成的部分接口；
- 第 12 章：当前只实现阵列层的保守准静态稳定部分。

整爪机构和整机 Newton–Euler 没有实现。
