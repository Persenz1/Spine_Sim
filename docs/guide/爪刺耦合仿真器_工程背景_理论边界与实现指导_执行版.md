# 0. 权威层级与冲突处理

本项目区分四个层级：

1. **完整理论层 T：** 定义真实问题中可能存在的几何、接触、柔顺、阵列和整爪平衡对象。
2. **项目模型层 P：** 当前仿真器实际实现的、可验证的降阶模型。本文件主要规定这一层。
3. **数值算法层 A：** 网格、插值、根求解、事件细化、缓存、并行和数据格式。
4. **验证层 V：** 解析夹具、极限关系、网格/步长收敛、配对 seed 统计和实验对照。

发生冲突时：

- 工程背景、模块职责、实现边界和筛选流程以本文件为准；
- 旧失败和禁止复用的语义以 04 文件为准；
- M2–M4 的物理公式若本文件未完整展开，以经审校的理论文件为准；
- 旧代码和旧结果只能作为诊断资料，不能反向定义新需求。

每项新增机制必须说明其所属层级、增加的论文价值、所需未知参数、验证方法和退出条件。不能因为完整理论中存在某机制，就把它自动变成首版强制实现。

# 1. 项目目标、最终交付与非目标

## 1.1 工程目标

建立以下因果链：

\[
\boxed{
\text{可复现地形}
\rightarrow
\text{有限针尖可达几何}
\rightarrow
\text{单刺路径响应}
\rightarrow
\text{共同背板阵列载荷共享}
\rightarrow
\text{十字对爪六维平衡}
}
\]

用于比较：

- 针尖半径、针径、安装角和轴向弹簧刚度；
- 刚性轴向安装与独立单边弹簧安装；
- 阵列规模、长宽方向、针距和角度梯度；
- 不同法向预载下的承载区间、载荷共享和事件后持续能力；
- 十字对爪在轴向与对角加载下的平衡、压紧—剥离关系和锁姿需求。

最终输出不是“唯一最优解”，而是：

\[
\boxed{3\text{ 种优势构型}+3\text{ 种机理对照构型}}
\]

三种对照构型不能只是排名最低或数值失败的方案。它们必须能正常建立预载、产生可测响应、可以制造，并与优势构型形成清楚的主差异，例如柔顺、阵列方向或角度布置差异。

## 1.2 当前不追求的目标

首版不承担：

- 预测某一块真实砖墙的绝对峰值或绝对成功概率；
- 复刻砖、混凝土、砂纸的完整功率谱、非高斯性和非平稳性；
- 从形貌仪器数据反演真实材料参数；
- 针尖压痕、脆性剥落、裂纹、碎屑、磨损和损伤后地形演化；
- 实时联立全部针、全部候选和整爪全部自由度；
- 结构强度认证或安全系数证明；
- 用一个综合分数代替原始力—位移、状态、事件和不确定性证据；
- UI、安装包、跨机图形界面和独立绘图模块。

## 1.3 完成标准

至少满足：

1. M1 的局部区域、最大区域和重新生成区域在重叠坐标上严格一致；
2. 平面、斜坡、单凸起、双凸起和正弦表面上的 M2 状态及力方向正确；
3. 单凸起能够接触—承载—脱离，双凸起能够脱离后继续并再次接触；
4. 弹簧刚度增大时连续趋近“关闭轴向弹簧、保留针体梁”的刚性安装；
5. 初始预载失败、路径中脱离、数值不收敛和模型未覆盖分别记录；
6. 阵列对称基准满足对称分载，局部事件后所有针在同一背板位姿重新评估；
7. 十字对爪的坐标旋转、wrench 搬移、压紧—剥离和锁姿需求通过手算夹具；
8. 主要结论在步长、10/5 μm 分辨率和 seed 追加后不过度翻转；
9. M0–M4 完成后全链试跑可受控结束、恢复和保存结果；
10. 最终 6 种构型具有明确选择证据和现实制造对照意义。

# 2. 固定工程背景

## 2.1 坐标系

墙面名义平面为全局 \(X-Y\) 平面，\(+Z\) 从墙面指向背板。

每个阵列单元采用局部右手系：

- 局部 \(+x\)：从单元头部指向根部，也是主动搜索和拖拽方向；
- 局部 \(-x\)：从根部指向头部；
- 局部 \(y\)：背板平面内、垂直单元中线；
- 局部 \(z\equiv +Z\)；
- \(\mathbf e_y=\mathbf E_Z\times\mathbf e_x\)。

针轴从安装座出口指向针尖球心。偏航 \(\beta=0\) 时：

\[
\mathbf a(\alpha)=\cos\alpha\,\mathbf e_x-\sin\alpha\,\mathbf E_Z.
\]

所有力、力矩和位移必须注明：

- 坐标系；
- 作用对象；
- 参考点；
- 正号。

六维 wrench 采用：

\[
\mathbf w=
\begin{bmatrix}
\mathbf F\\
\mathbf M
\end{bmatrix}.
\]

## 2.2 单刺设计空间

- 针尖局部球面半径：\(R_t=50,100\ \mu\mathrm m\)；
- 针杆直径：\(d=0.6,0.8\ \mathrm{mm}\)；
- 固定安装角时轴向露出长度：\(L_e=4\ \mathrm{mm}\)；
- 安装角候选：\(50^\circ,60^\circ,70^\circ,80^\circ\)；
- 偏航角：首版固定为零；
- 针体材料类别：高碳钢，具体牌号未冻结，材料参数必须显式记录；
- 针体梁：正式比较默认保留主平面低阶梁柔顺；
- 真实端部为球冠—锥段—圆柱杆，完整球只作为有限针尖局部代理。

## 2.3 阵列设计空间

规则矩形田字格：

\[
n_x,n_y\in\{2,3,4,5,6\},
\qquad
s_x=s_y\in\{4,5,6\}\ \mathrm{mm}.
\]

\(2\times5\) 与 \(5\times2\) 是不同设计。

固定角阵列使用同一 \(\alpha\)。角度梯度只沿局部 \(x\) 变化：

- \(80^\circ\rightarrow50^\circ\)；
- \(80^\circ\rightarrow60^\circ\)。

为使未加载针尖球心法向高度一致：

\[
L_j\sin\alpha_j=4\sin80^\circ\ \mathrm{mm},
\qquad
L_j=\frac{4\sin80^\circ}{\sin\alpha_j}\ \mathrm{mm}.
\]

安装模式：

- **刚性轴向安装：** 关闭串联轴向弹簧，\(\delta_s=0\)，针体梁仍可变形；
- **独立弹簧安装：** 每针具有轴向单边弹簧，\(100\le k_s\le2000\ \mathrm{N/m}\)，行程 \(0\le\delta_s\le4\ \mathrm{mm}\)，无预压、不可受拉、到行程后进入硬限位。

若轴向弹簧和针体梁同时关闭，粘着反力可能不唯一。不得用任意大罚刚度伪造唯一力—位移曲线。

## 2.4 加载路径

2026-07-28 用户修订了预载边界：预载是整个拖动过程中持续施加的恒定外力，不能
只在起点建立后冻结 Z。

- 单刺名义持续外部法向预载：\(0.5\ \mathrm N\)；
- 阵列和十字对爪名义持续总外部预载：每单元 \(0.5\)–\(2\ \mathrm N\)；
- 拖拽方向：局部 \(+x\)；
- 物理速度：\(1\ \mathrm{mm/s}\)，采用时域动力学推进；
- 最长拖拽行程：\(100\ \mathrm{mm}\)。

恒定的是执行器施加的外力，不是每个接触点、每根针或每一瞬间的接触反力。脱离
时接触反力可以为零，冲击时可以超过名义预载。

参考路径允许：

\[
\text{FREE}
\rightarrow
\text{CONTACT}
\rightarrow
\text{STICK/SLIDE}
\rightarrow
\text{DETACH}
\rightarrow
\text{FREE}
\rightarrow
\text{RECONTACT}.
\]

## 2.5 十字对爪几何

四个单元中线沿全局 \(\pm X,\pm Y\)。单元参考点距中心 \(C\) 的名义半跨：

\[
a=40\ \mathrm{mm}.
\]

外载点：

\[
\mathbf r_P=[0,0,50\ \mathrm{mm}]^T.
\]

正式比较方向：

\[
\hat{\mathbf d}_A=\mathbf E_X,
\qquad
\hat{\mathbf d}_B=\frac{\mathbf E_X+\mathbf E_Y}{\sqrt2}.
\]

外载 wrench 关于中心：

\[
\mathbf F_{\mathrm{ext}}=\lambda\hat{\mathbf d},
\qquad
\mathbf M_{\mathrm{ext}}=\mathbf r_P\times\mathbf F_{\mathrm{ext}}.
\]

# 4. 总体建模和软件原则

## 4.1 必须保留的因果关系

- 几何候选不等于稳定承载；
- 法向接触力不能为负；
- FREE 是正常物理状态，不是 case 失败；
- 脱离时接触力为零，但路径继续；
- 阵列中所有针共享同一背板位姿；
- 局部状态变化后，全阵列必须在当前共同位姿重新评估；
- wrench 必须搬移到同一参考点后相加；
- 首个局部事件不自动等于阵列或整爪极限；
- 力、矩和状态样本不能跨 seed、跨路径位置或跨状态分支拼接；
- 物理、数值、模型和运行状态必须分开。

## 4.2 每轮仿真后的决策门

每轮 campaign 必须输出：

1. 数据完整性和异常审计；
2. 配对 seed 统计；
3. 主要效应与关键交互；
4. 排名或 Pareto 集的 bootstrap 稳定性；
5. 被淘汰变量和保留变量的物理理由；
6. 下一轮候选空间、seed 数、行程和预载建议；
7. 明确标记“建议继续”“需要补算”或“当前不能下结论”。

下一轮不能由代码自动启动。先审查分析报告，再生成新的 campaign 配置。

## 4.3 不允许用一个综合分数决定结果

筛选顺序：

1. **硬门禁：** 排除数值失败、模型超范围、异常残余、不可制造或需要不现实约束的构型；
2. **Pareto 分析：** 同时比较低分位承载、有效承载长度、载荷共享、稳定性和制造复杂度；
3. **行为聚类：** 区分高峰值但集中、稳健共享、频繁再挂接、方向敏感等行为；
4. **匹配对照：** 从可工作构型中选择主差异清楚的对照，而不是选择最差三个。

## 5.2 结果格式

稳定字段至少包括：

```text

├── manifest.json
├── config/
├── cases.parquet
├── paths/
├── events.parquet
├── validation.json

```

单个模块可使用：

顶层至少分为：

| 维度 | 示例 |

| physical_state | free / contact / stick / slide / hard_stop / failed |

业务摘要可以生成 `completed_with_recontacts` 等标签，但不得覆盖原始状态。

# 6. M1：地形库与有限针尖几何

## 6.1 M1 的核心决策

采用三层结构：

\[
\boxed{
\text{地形配方}
\rightarrow
\text{本地最大需求区域}
\rightarrow
\text{运行时一维轨迹缓存}
}
\]

具体决策：

- 每个 seed 在 10 μm 生产分辨率下保存一块统一的最大需求原始地形；
- 运行时用只读 memory map 访问，不要求完整数组长期驻留 RAM；
- 不长期驻留显存；
- 不按每个阵列构型分别生成独立随机地形；
- 不默认保存完整二维有限针尖包络；
- M2/M3 主要读取固定 \(y_i\) 上的一维有限针尖轨迹；
- 5 μm 只用于最终少量地形和候选的收敛复核，完整 5 μm 原始地形不保存到本地；
- 配方和 seed 永久保存，缓存均可删除后重建；
- 需要完整或更大地形时，可以按同一配方和全局坐标重新生成任意区域。

## 6.2 解析和项目地形

必须支持：

### 解析夹具

- 平面；
- 单斜坡；
- 单个光滑凸起；
- 两个分离凸起；
- 一维正弦；
- 可选二维正弦或交叉坡面。

### 项目输入

1. 简单有 seed 的 `defined_geometry`；
2. 文件读取的测量或人工高度图。

缺少真实表面标定时，不得使用 `brick_like`、`concrete_like` 等名称暗示材料真实性。

## 6.3 可重建地形配方

配方至少包含：

```text
TerrainRecipe
├── terrain_recipe_id
├── generator_name
├── generator_version
├── seed
├── global_origin_x
├── global_origin_y
├── canonical_dx = 5 μm
├── production_dx = 10 μm
├── target_rms_height
├── correlation_length_x
├── correlation_length_y
├── kernel_definition
├── amplitude_scale
├── coordinate_convention
└── recipe_hash
```

随机场必须按全局网格坐标可寻址。同一 seed、同一配方、同一全局坐标无论在何种窗口中生成，都必须得到相同值。

禁止：

- 依赖从数组左上角顺序消耗随机数；
- 每个局部窗口单独减均值、除以自身 RMS；
- 因区域尺寸变化而改变地形幅值；
- 只靠相同整数 seed 但生成不同实际地形来做 10/5 μm 收敛。

推荐基线：

\[
\epsilon_{ij}=\mathcal R(\text{seed},i,j,\text{generator version}),
\]

\[
h=S_q\,C_G\,(G_{\ell_x,\ell_y}*\epsilon),
\]

其中 \(G\) 使用固定物理尺度和有限截断支撑，\(C_G\) 由核权重确定，不依赖当前窗口的样本统计。

5 μm 为规范网格。10 μm 生产数据固定取规范网格在全局坐标上对齐的偶数节点，即每两个 5 μm 节点取一个，不做 2×2 局部平均，也不重新滤波或归一化。生成 10 μm 文件时允许按 tile 生成 5 μm 工作区并立即抽取偶数节点，不要求把整张 5 μm 地形放入内存。该规则进入生成器版本。

## 6.4 最大需求区域

原始地形不按构型保存，而按 campaign 的最大几何需求保存。

区域边界由程序根据以下信息自动计算：

- 最长拖动距离 \(L_{\mathrm{drag}}=100\ \mathrm{mm}\)；
- 最大阵列 \(6\times6\)；
- 最大针距 \(6\ \mathrm{mm}\)，安装点最大跨度 \(30\ \mathrm{mm}\)；
- 固定角和梯度角下的最大针尖水平投影；
- 最大针尖半径；
- 梁/弹簧可能位移；
- 插值、包络和事件细化余量；
- 杆体净空检查余量；
- 随机场滤波 halo。

形式上：

\[
x_{\min}=\min_{d,i}(x^0_{i,d}+p_{x,i,d})-m_x,
\]

\[
x_{\max}=L_{\mathrm{drag}}+\max_{d,i}(x^0_{i,d}+p_{x,i,d})+m_x,
\]

\[
y_{\min}=\min_{d,i}y^0_{i,d}-m_y,
\qquad
y_{\max}=\max_{d,i}y^0_{i,d}+m_y.
\]

预计量级约为 \(140\)–\(150\ \mathrm{mm}\times40\)–\(50\ \mathrm{mm}\)，但不得把该数值硬编码；必须保存实际计算依据。

## 6.5 本地地形库和内存策略

推荐目录：

```text
terrain_library/
├── recipes/
├── sources/
├── regions/
│   └── <terrain_recipe_id>/<region_id>/raw_height_10um.npy
├── tracks/
│   └── <terrain_recipe_id>/<region_id>/<radius>/<track_id>.npz
├── manifests/
└── validation/
```

运行时：

```python
height = np.load(path, mmap_mode="r")
```

含义：

- 文件是权威缓存；
- 操作系统页缓存自动决定哪些区域驻留 RAM；
- 多进程可以共享只读页缓存；
- 不把所有 seed 同时加载；
- 按 terrain seed 分组运行全部构型，提高缓存命中；
- case 或 seed 完成后释放普通临时数组。

在约 \(150\times50\ \mathrm{mm}\)、10 μm、`float32` 下，单 seed 原始地形约 300 MB。50–80 个 seed 约 15–24 GB，只保存原始高度和小型轨迹缓存时可控。

## 6.6 有限针尖包络和轨迹缓存

完整球代理：

\[
H_R(X,Y)=
\max_{(u,v):\rho\le R}
\left[
 h(u,v)+\sqrt{R^2-\rho^2}
\right].
\]

对固定横向轨迹 \(y_i\)，M1 输出：

```text
TrackGeometry
├── terrain_recipe_id
├── region_id
├── track_id
├── radius
├── y_global
├── x_global
├── envelope_height
├── envelope_slope_x
├── support_x
├── support_y
├── valid_mask
├── near_tie_flag
└── model_warning
```

M2/M3 默认只消费一维轨迹。M1 可以保留完整二维包络生成函数用于解析验证、调试和未来横向运动，但不把完整二维包络、二维梯度和支撑坐标作为生产默认文件。

所有构型必须共享同一 terrain recipe、region 和全局坐标。不同针尖半径可以有不同轨迹缓存，但不能为每根针重新生成一张相似而不相同的随机地形。

## 6.7 球冠和杆体门控

完整球包络只是局部代理。候选点至少满足前向球冠条件：

\[
(\mathbf q-\mathbf c)\cdot\mathbf a\ge0.
\]

杆体/锥段碰撞首版采用：

- 解析夹具中关闭并标记；
- 项目地形中可选低成本线段或圆柱净空检查；
- 几何未闭合时输出 `model_unclosed_rod_collision`，不能直接判为挂接失败；
- 不建立杆体分布承载。

## 6.8 10/5 μm 策略

- 10 μm：生产分辨率，原始地形保存到本地；
- 5 μm：只对最终少量地形和候选做收敛复核；
- 5 μm 完整原始场按 tile 或单 seed 在内存中生成，完成后释放；
- 不保存完整 5 μm 原始地形，只保存配方、实际轨迹、结果和 10/5 μm 对照摘要；
- 5 μm 与 10 μm 必须来自同一规范地形，不能只是相同 seed 的两张独立表面。

5 μm 复核对象建议包括：

- 5–10 个代表 seed；
- 容易、中等、困难和事件密集地形；
- 8–10 个终筛候选或至少最终 6 个构型。

## 6.9 M1 验收

必须通过：

- 平面包络；
- 斜坡解析偏移；
- 单凸起首次接触方向；
- 同配方同区域完全复现；
- 局部窗口与最大区域裁剪一致；
- 相邻 tile 重叠区域一致；
- 10 μm 节点与重新生成的 5 μm 规范地形一致；
- CPU/GPU 在声明容差内一致；
- 删除缓存后可由配方重建；
- memory map 运行；
- 网格加密后包络、导数和事件位置收敛。

# 7. M2：单刺规定姿态本构与参考路径

## 7.1 M2 回答的问题

给定一根针、一个确定性有限针尖轨迹和一条安装座路径，计算：

- 是否建立初始预载；
- 何时 FREE、接触、粘着、滑移、硬限位、脱离和再次接触；
- 实际法向、切向力如何变化；
- 轴向弹簧和针体梁如何分担位移；
- 根部 wrench 和物理/数值余量；
- 有效承载区间，而不是“是否全程维持精确恒力根”。

## 7.2 两层入口

### 规定安装座位姿本构核心

输入：

- 当前安装座 \((x_h,z_h)\)；
- 针刺参数；
- M1 `TrackGeometry`；
- 上一步已接纳状态；
- `commit=False/True`。

输出：

- 接触和弹簧状态；
- 接触力、弹簧压缩和梁变形；
- 关于安装点的 wrench；
- proposal state；
- 物理、数值和模型残余。

核心不得读取目标法向力，也不得自行移动安装座。

### 单刺动力学试验

参考流程：

1. 在持续外部预载下建立初始静态平衡；
2. 初速度置零；
3. 保持外部预载不变，以 \(1\ \mathrm{mm/s}\) 沿局部 \(+x\) 拖动；
4. 安装座 \(z_h(t)\) 和针体动态变形作为未知量积分；
5. 脱离后接触力为零，但预载继续驱动系统靠近表面；
6. 冲击和再次接触由接触动力学处理；
7. 汇总稳态力、冲击峰、接触占空比、结构裕度和能量残余。

详细权威定义见 `docs/M2_DYNAMIC_CONSTANT_PRELOAD_SPEC.md`。

## 7.3 状态

接触状态：

- `FREE`；
- `FIRST_CONTACT_EVENT`；
- `STICK`；
- `SLIDE`；
- `DETACH_EVENT`；
- `RECONTACT_EVENT`。

弹簧状态：

- `LOWER_STOP`；
- `INTERIOR`；
- `HARD_STOP`。

初始预载失败只能在初始预载阶段记录为 `initial_preload_infeasible`。拖动中的失去接触必须记录为 `detach_to_free`。

## 7.4 运动学和柔顺

\[
\mathbf c=
\mathbf r_h+(L-\delta_s)\mathbf a+\mathbf u_b.
\]

主平面内与针轴垂直的单位向量：

\[
\mathbf b=\sin\alpha\,\mathbf e_x+\cos\alpha\,\mathbf E_Z.
\]

若墙面对针的合力为 \(\mathbf f\)：

\[
Q_s=-\mathbf f\cdot\mathbf a,
\qquad
V_b=\mathbf f\cdot\mathbf b.
\]

单边弹簧：

\[
0\le\delta_s\le\delta_{\max}=4\ \mathrm{mm}.
\]

- \(Q_s\le0\)：\(\delta_s=0\)；
- \(0<Q_s<k_s\delta_{\max}\)：\(\delta_s=Q_s/k_s\)；
- \(Q_s\ge k_s\delta_{\max}\)：进入硬限位。

针体截面：

\[
A=\frac{\pi d^2}{4},
\qquad
I=\frac{\pi d^4}{64}.
\]

首版端部柔顺：

\[
c_a=\frac{L}{EA},
\]

\[
c_b=\frac{L^3}{3EI}+\frac{L}{\kappa GA}.
\]

\[
\mathbf u_b=-c_aQ_s\mathbf a+c_bV_b\mathbf b.
\]

## 7.5 接触与摩擦

\[
\mathbf f=\lambda_n\mathbf n+f_t\boldsymbol\tau,
\qquad
\lambda_n\ge0.
\]

静摩擦：

\[
|f_t|\le\mu_s\lambda_n.
\]

滑移：

\[
f_t=-\mu_k\lambda_n\operatorname{sign}(v_{\mathrm{rel},t}).
\]

STICK 必须有明确接触锚点或切向历史约束。不得只检查摩擦不等式后任意指定切向力。

首版不使用负间隙乘任意罚刚度生成法向力。规定安装座位姿下，由非穿透、接触状态和结构相容共同决定反力。

## 7.6 单步求解和路径终止

单步：

1. 从上一状态预测球心；
2. 查询 M1 轨迹、支撑点、切向、法向和球冠门控；
3. 正间隙且无历史接触约束时返回 FREE；
4. 闭合后求接触、弹簧和梁相容；
5. 先试 STICK，超出静摩擦界后转 SLIDE；
6. 要求负法向力或几何开离时 DETACH→FREE；
7. 检查弹簧三段状态；
8. 计算 wrench、能量和残余；
9. 所有检查通过后 commit；
10. 继续到下一安装座位置。

只在粗步跨越宏观接触、脱离、滑移起始或硬限位时局部细化。不追踪纳米级反复切换。

路径只有在以下情况终止：

- 到达终点；
- 地形域耗尽；
- 显式结构边界越界；
- 局部重试后仍数值失败；
- 参数或模型接口未闭合；
- 用户规定的安全位移边界到达。

## 7.7 M2 输出和筛选职责

逐点和路径摘要至少包括：

- 安装座、球心和支撑点；
- gap、切向、法向和门控；
- 接触/弹簧状态；
- 接触力和根部 wrench；
- \(Q_s,V_b,\delta_s,\mathbf u_b\)；
- 摩擦、行程、碰撞和模型余量；
- 数值残余、迭代、事件和能量审计；
- 初始预载成功；
- 是否曾承载；
- 总接触长度；
- 有效承载长度；
- 最大连续承载距离；
- 切向力中位数和低分位；
- 实际法向力范围；
- 再接触、滑移、脱离和硬限位次数。

M2 的参数筛选重点是：

- 针尖半径；
- 刚性/弹簧安装；
- 弹簧刚度有效区间；
- 针径趋势。

安装角在 M2 中必须保留代表值进行敏感性分析，但不要求 M2 直接冻结唯一角度。安装角可能与阵列方向、角度梯度和载荷共享发生交互，应允许进入 M3 继续判断。

# 8. M3：共同刚性背板阵列

## 8.1 目标

M3 研究共同背板约束下：

- 哪些针接触；
- 载荷如何共享和集中；
- 弹簧刚度、阵列方向、针距和角度布置如何改变活动针数；
- 某根针脱离后其他针如何在同一背板位姿改变载荷；
- 单元合力、合矩和 M4 所需同状态样本如何形成。

## 8.2 共同位姿和边界

首版：

\[
\mathbf q_B=
\begin{bmatrix}
u_x\\
u_Z
\end{bmatrix}.
\]

第 \(i\) 根针安装点：

\[
\mathbf r_{h,i}=\mathbf r_{h,i}^{0}+u_x\mathbf e_x+u_Z\mathbf E_Z.
\]

试验流程：

1. 在起点用持续总外部预载建立共同背板初态；
2. 保持该外部总预载不变；
3. 令共同 \(u_x(t)=u_x^0+v_{\rm drag}t\)；
4. 将共同 \(u_Z(t)\)（以及声明允许的转角）作为动力学自由度；
5. 组装每根针的 M2 动力学单元并统一时域积分；
6. 脱离针接触力为零，仍参与后续冲击和再接触。

禁止为每根针施加独立恒定预载，也禁止在每步强制总接触反力精确等于外部预载。
外部预载恒定，但总接触反力可以因背板惯性和冲击而波动。

## 8.3 原子状态更新

对同一旧 `ArrayDynamicState`：

- 所有针从该同一旧状态形成一个全局动力学 proposal；
- 非线性/接触迭代期间不得提交任何单针历史；
- 全局步通过后一次性提交，拒绝时保持旧状态；
- 不允许先提交部分针，再用已改变状态计算其他针；
- 不复用独立 M2 完整路径结果拼接阵列响应。

## 8.4 单元 wrench

逐针根部 wrench 关于安装点为 \((\mathbf F_i,\mathbf M_{r,i})\)。搬移到单元参考点 \(O_U\)：

\[
\mathbf M_i^{O_U}=\mathbf M_{r,i}
+(\mathbf r_{h,i}-O_U)\times\mathbf F_i.
\]

单元合 wrench：

\[
\mathbf w_U^{O_U}=\sum_i
\begin{bmatrix}
\mathbf F_i\\
\mathbf M_i^{O_U}
\end{bmatrix}.
\]

主动推力和导向反力单独保存，不重复计入墙面对单元的接触 wrench。

## 8.5 活动集和有效针数

至少区分：

- \(\mathcal I_{\mathrm{nom}}\)：名义安装；
- \(\mathcal I_{\mathrm{geom}}\)：具有几何闭合机会；
- \(\mathcal I_{+}\)：具有正法向反力；
- \(\mathcal I_{\mathrm{adm}}\)：摩擦和结构可行；
- \(\mathcal I_{\mathrm{load}}\)：实际承担目标载荷。

对明确的非负载荷权重：

\[
N_{\mathrm{eff}}^{(a)}=
\frac{1}{\sum_i(\eta_i^{(a)})^2}.
\]

法向、目标切向和合力指标分别报告，不能用一个未说明权重的 \(N_{\mathrm{eff}}\) 混合解释。

## 8.6 M3→M4 数据

保存同一路径位置和同一状态分支上的原始样本：

```text
unit_sample
├── seed
├── terrain_recipe_id
├── path_position
├── preload
├── normal_force
├── tangential_force_positive
├── tangential_force_negative
├── unit_moment
├── active_set
├── contact_states
├── event_label
├── numerical_residual
└── model_level
```

不能跨 seed、跨路径位置或跨状态分别挑选最有利力和力矩。

## 8.7 M3 输出

- 共同 \(u_x,u_Z\)；
- 单元合力、合矩和端口需求；
- 每针位置、接触力、状态、弹簧和梁变量；
- 活动集、\(N_{\mathrm{eff}}\) 和载荷集中度；
- 事件前后载荷重分配；
- 峰值、低分位、有效承载长度和事件后持续能力；
- 硬限位、脱离和再接触统计；
- M4 原始能力样本。

安装角的最终取舍主要在 M3 中结合阵列方向、角度梯度、载荷共享和预载敏感性判断，不能只根据单刺峰值决定。

# 9. M4：十字对爪降阶平衡

## 9.1 定位

M4 不实时展开所有针，而是读取 M3 的同状态单元样本，完成：

- 四单元坐标旋转；
- wrench 搬移到整爪中心；
- 偏心外载力矩；
- 四单元静力平衡；
- 压紧侧和剥离侧；
- 能力利用率、锁姿需求和静力边界；
- 轴向与对角加载比较。

## 9.2 坐标搬移

第 \(i\) 个单元局部到全局旋转为 \(\mathbf R_i\)，中心到单元参考点位置为 \(\mathbf r_i\)：

\[
\mathbf F_i^C=\mathbf R_i\mathbf F_i^{O_i},
\]

\[
\mathbf M_i^C=
\mathbf r_i\times\mathbf F_i^C
+\mathbf R_i\mathbf M_i^{O_i}.
\]

若已保留完整单元矩，不得再用等价压力中心重复计矩。

## 9.3 六维平衡

\[
\sum_{i=1}^{4}\mathbf F_i^C+
\mathbf F_{\mathrm{ext}}+
\mathbf F_{\mathrm{constraint}}=0,
\]

\[
\sum_{i=1}^{4}\mathbf M_i^C+
\mathbf M_{\mathrm{ext}}+
\mathbf M_{\mathrm{constraint}}=0.
\]

对 \(+X\) 外载，低阶法向差动满足：

\[
a(N_{+X}-N_{-X})\approx h\lambda.
\]

因此 \(+X\) 侧压紧、\(-X\) 侧卸载。

## 9.4 首版边界

首版只实现姿态锁定静力模型：

- 初始法向预载按输入给定；
- 外部机构允许提供绕 \(X/Y\) 的锁姿矩；
- 约束机构不得承担未声明的墙面内外力；
- 输出 `lock_wrench_required`；
- 锁姿容量未知时只报告需求，不声称结构必然可实现；
- 不做被动摇摆、大角度倾覆和实时 M3 嵌套。

允许计算理想法向自由重分配上界，但必须命名为 `lambda_static_ub`，不能称为真实被动承载力。

## 9.5 能力使用限制

- 只在 M3 声明的有效法向范围内插值；
- 不向上外推；
- 力、矩、活动集和状态必须来自同一物理样本或同一保守下包络；
- 没有局部 \(y\) 响应时，不能虚构单个单元完整二维切向能力；
- 对角加载仅在已声明的轴向单元 ROM 范围内解释。

## 9.6 极限和输出

分开报告：

- `lambda_first`：首个单元达到局部边界；
- `lambda_eq`：允许规定重分配后无静力平衡；
- `lambda_limit_ROM`：当前降阶状态规则下的路径终点；
- `lambda_static_ub`：理想法向自由分配上界。

输出：

- 四单元 \(N_i,T_i,\mathbf M_i\)；
- 合力/合矩残余；
- 锁姿 wrench；
- 压紧侧、剥离侧；
- 能力利用率和边界模式；
- 来源构型、seed、预载、路径位置和模型等级；
- `formal_system_conclusion_allowed` 标记。

- 原子写入和断点恢复；
- Windows/Linux 路径；
- 多进程 case 隔离；
- 无 GPU 完整运行。

## 11.2 M1→M2 门禁

- 平面、斜坡、凸起包络；
- 局部/完整区域一致；
- 10/5 μm 规范地形一致；
- 网格收敛；
- memory map 和删除后重建。

## 11.3 M2→随机筛选门禁

- 平面；
- 斜坡；
- 单凸起；
- 双凸起；
- 正弦；
- 刚性极限；
- 针径柔顺趋势；
- 脱离后继续；
- 状态分离；
- 能量和异常残余可解释。

任一未通过，不得进入随机地形粗筛。

## 11.4 M2→M3 门禁

- 同 seed 重复结果一致；
- 步长减半后主要指标收敛；
- 无未解释异常峰值；
- 初步参数趋势对数值设置不敏感；
- M2 规定姿态接口和 proposal/commit 稳定。

## 11.5 M3→M4 门禁

- 对称两针/四针均载；
- 高度差接触顺序；
- 柔顺影响方向；
- 局部脱离后的全阵列重评估；
- 合力/合矩残余；
- 力和矩来自同一状态；
- 能力样本覆盖目标预载范围。

## 11.6 全链试跑

M4 验收后，先运行极小全链：

- 1 个解析地形；
- 1 个随机 seed；
- 1 个单刺参数包；
- 1 个小阵列；
- 1 个十字对爪加载方向；
- 短路径和少量载荷步。

目标只检查：

- 接口；
- 坐标和参考点；
- 状态传递；
- 数据字段；
- 运行恢复；
- 错误是否能局部终止并保存。

全链跑通不等于物理验收。修复后必须重新运行相关模块夹具。所有夹具和全链 smoke 通过后，冻结版本并生成 `full_chain_frozen_manifest.json`，再开始正式 campaign。正式 campaign 顺序为 M2 单刺筛选→人工决策→M3 阵列筛选→人工决策→M3/M4 细筛与终筛。

# 12. 自适应粗筛、细筛和终筛

## 12.1 总原则

- 每一轮结束先分析，不能自动运行下一轮；
- 每个构型使用相同配对 seed；
- seed 数按地形配方分别计算，不把不同统计配方混成同一总体；
- 先使用一个明确标记的基准 `defined_geometry` 配方；
- 是否增加粗糙度或相关长度配方，由早期分析决定；
- 10 μm 用于生产，5 μm 只用于最终收敛复核。

## 12.2 M2 第一轮：单刺粗筛

目标：主要压缩针尖半径、安装模式和弹簧刚度，检查针径趋势，同时保留安装角不确定性。

建议初始设计：

- \(R_t=50,100\ \mu\mathrm m\)；
- \(d=0.6,0.8\ \mathrm{mm}\)；
- 安装状态：刚性 + 4 个近似对数分布的弹簧刚度代表点；
- 安装角代表值：\(60^\circ,70^\circ,80^\circ\)；
- \(50^\circ\) 作为边界候选，是否加入第二轮由第一轮决定；
- 初始预载：\(0.5\ \mathrm N\)；
- 完整行程：100 mm；
- 第一轮配对地形：15 个 seed；
- 第一轮结束后先分析；只有人工批准第二轮时，才使用另外 30 个独立配对 seed
  做局部加密。两轮合计预生成 45 个地形，但预生成不等于授权启动第二轮。

分析重点：

- 半径和刚度的配对效应；
- 刚性极限与高刚度弹簧的连续性；
- 针径对稳定性、硬限位和低分位承载的影响；
- 安装角是否与半径/刚度存在明显交互；
- 需要保留到 M3 的参数包。

M2 不应仅保留“峰值最高”的参数。建议形成 8–12 个单刺参数包：优势、边界和机理对照均有覆盖。

## 12.3 M2 第二轮：数据驱动局部加密

只有第一轮分析完成后才决定：

- 在优势刚度区间增加哪些点；
- 是否加入 \(50^\circ\)；
- 第二轮固定使用预留的另外 30 个独立配对 seed，不与第一轮 15 个 seed 混成
  “30 个总样本”；
- 是否可以固定某个针尖半径；
- 是否可以淘汰某些安装模式或针径。

M2 的目标是把半径和弹簧刚度估计到足以进入阵列设计的范围，不强求单刺层冻结唯一安装角。

## 12.4 M3 第一轮：阵列粗筛

输入 M2 已批准的参数包。代表阵列优先覆盖：

- \(2\times2\)；
- \(2\times5\)、\(5\times2\)；
- \(3\times5\)、\(5\times3\)；
- \(4\times4\)；
- \(6\times6\)；
- 针距 4/5/6 mm；
- 固定角和梯度角模式。

不做全部笛卡尔积。使用平衡离散设计或贪心覆盖，建议 80–120 个硬件候选上限。

初始运行条件：

- 12–16 个配对 seed；
- 10 μm；
- 每单元中等预载，例如 1 N；
- 50 mm 粗筛路径；
- 少量代表构型同时跑 100 mm，检查短路径排名偏差。

分析后保留约 18–24 个候选，覆盖：

- 综合较强；
- 载荷共享较好；
- 方向/角度机理差异明显；
- 对预载可能敏感、需要细筛的边界构型。

## 12.5 M3/M4 细筛

对 18–24 个候选：

- 配对 seed 增至 30；
- 完整 100 mm 路径；
- 每单元预载 \(0.5/1.0/2.0\ \mathrm N\)；
- M4 轴向和对角加载；
- 检查锁姿需求和能力有效范围。

分析后保留约 8–10 个终筛候选。

## 12.6 终筛

对 8–10 个候选：

- seed 追加到 50–80；
- 10 μm 完整路径和规定预载；
- bootstrap 检查排名、Pareto 集和进入前 \(k\) 名概率；
- 检查低分位、尾部、方向敏感性和预载敏感性；
- 对 5–10 个代表 seed 做 5 μm 复核；
- 若 50–80 个 seed 时结论仍频繁翻转，才考虑增加到 100 以上。

## 12.7 最终 6 种的选择

三种优势构型建议从不同角色中选择：

1. 稳健低分位承载型；
2. 载荷共享和事件后持续能力型；
3. 制造简单但性能接近前沿型。

三种对照构型应尽量形成匹配对照：

1. 柔顺差异；
2. 阵列方向或形状差异；
3. 安装角/角度梯度或针距差异。

最终具体对照轴由数据决定。对照构型必须可工作、可制造、数值可信，不能只是“最差三个”。

# 13. 数值、性能和 GPU 策略

## 13.1 先正确后优化

每个模块先建立 CPU 参考实现。任何优化必须证明物理结果在声明容差内不变。

## 13.2 网格和步长

- 10 μm 为生产地形分辨率，不是先验真值；
- 5 μm 用于最终候选收敛；
- 至少检查包络、事件位置、有效承载长度和稳健力指标；
- 普通路径用粗步，宏观事件附近局部细化；
- 不在整条路径使用极小步长；
- 数值容差不能当成物理阈值。

## 13.3 GPU

GPU 适合：

- 大数组随机场 tile 生成；
- 有限针尖几何批量预计算；
- 多个独立地形的离线处理。

GPU 不作为 M2/M3 高频小粒度状态机的权威查询源。推荐：

- CPU 必须完整可运行；
- 有 NVIDIA GPU 时可加速 M1；
- 10 μm 原始地形写入本地后用 CPU memory map；
- 不长期驻留显存；
- 独立 case/seed 多进程，不跨 GPU 通信。

# 14. 旧资产处置与禁止性规则

## 14.1 可保留

- 坐标、单位和 wrench 约定；
- seed/case/campaign identity；
- 有限球包络算法，经新夹具验证后复用；
- CPU/GPU 一致性测试；
- CUDA 生成后 CPU 查询经验；
- 独立 case 多进程；
- 旧结果只读工具。

## 14.2 只能逐项参考

- 弹簧和梁公式；
- 摩擦代码；
- 阵列几何和 wrench 聚合；
- M4 坐标旋转和静力求解；
- 旧 Schema 和结果 validator。

## 14.3 禁止复用或禁止行为

1. 禁止把每步精确恒法向力根作为挂接成功定义；
2. 禁止初始预载成功后仍使用 `preload_infeasible` 描述拖动脱离；
3. 禁止第一次脱离即终止完整路径；
4. 禁止每针独立求法向位置或人为平均分载；
5. 禁止负间隙乘任意罚刚度代替接触相容；
6. 禁止关闭弹簧和梁后由数值正则化输出唯一反力并称为物理结果；
7. 禁止跨 seed、跨状态拼接最大力和最有利力矩；
8. 禁止将软件测试、GPU 一致性或全链跑通视为物理验收；
9. 禁止在夹具未通过前运行大规模参数扫描；
10. 禁止把真实材料名称赋予未标定合成地形；
11. 禁止完整二维地形、包络、导数和支撑数组全部长期驻留内存或显存；
12. 禁止未经数据分析和人工确认自动启动下一轮 campaign；
13. 禁止覆盖旧 9,600-case 工作区。

# 15. 最终判断

本项目的主线不是建立高保真数字孪生，而是建立一条可验证、可复现、可用于现实构型选择的工程因果链：

1. M0 提供轻量但可靠的基础；
2. M1 用可重建配方、10 μm 本地最大区域和一维轨迹缓存控制数据规模；
3. M2 正确表达接触—承载—脱离—再接触，并重点缩小针尖半径和弹簧刚度范围；
4. M3 在共同背板下判断安装角、阵列方向、针距和角度梯度；
5. M4 在明确降阶边界下完成十字对爪平衡和候选终筛；
6. 每轮先分析再决策，最终选择 3 种优势构型和 3 种可解释的对照构型进入制造实验。

只要该链条通过解析夹具、数值收敛、配对 seed 和全链接口验证，且最终构型在现实实验中能够检验趋势和机理，项目目标即成立。
