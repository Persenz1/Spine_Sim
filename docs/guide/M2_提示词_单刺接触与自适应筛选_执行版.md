# M2 提示词：持续恒载动力学单刺

## 一、任务身份

你负责重建 M2。2026-07-28 用户确认：旧版“只在起点建立预载，随后固定
\(z_h\) 拖动”的冻结边界错误。M2 的真实试验是持续施加恒定外部法向预载，同时
以规定速度在地形上拖动；针尖脱离、弹跳、冲击和再接触属于动力学过程。

本提示词替代所有旧 fixed-Z M2 指令。详细方程和验收以
`docs/M2_DYNAMIC_CONSTANT_PRELOAD_SPEC.md` 为准。

## 二、权威输入

完整阅读：

1. `docs/M2_DYNAMIC_CONSTANT_PRELOAD_SPEC.md`；
2. 更新后的共享工程指导文档；
3. M1 `TrackGeometry` 与 `M1_to_M2_handoff.md`；
4. M0 结果、原子写入和 campaign 接口；
5. `M2_DATA_DICTIONARY.md` 与 `M2_to_M3_handoff.md`。

若旧文档或旧测试要求“initial preload + fixed Z”，该要求已失效，不得兼容为正式
生产模式。

## 三、任务目标

实现两个边界清楚的入口：

1. 可复用的单针动力学单元：结构恢复力、质量/阻尼、M1 包络接触、碰撞和摩擦；
2. M2 时域试验：持续外部预载、规定水平速度、自由竖向运动、完整 100 mm 路径。

旧 `PrescribedPoseConstitutiveCore` 可以暂时保留为解析夹具或 M3 迁移兼容层，但
不得再作为正式 M2 路径的物理内核，也不得生成可排名结果。

## 四、不可混淆的载荷语义

- 恒定的是外部输入 \(F_{\rm preload}\)；
- 接触反力在脱离时为零，在冲击时可高于名义预载；
- 不在每个时刻强制接触反力等于预载；
- 不冻结安装座 Z；
- 阵列中恒定的是背板总外部预载，不是每针预载。

## 五、实现门禁

按顺序完成：

1. 动力学参数模型、状态和确定性积分框架；
2. 平面持续恒载静止/滑动；
3. 单边接触、脱离、自由飞行、冲击和再接触；
4. 轴向弹簧三段与横向梁模态；
5. STICK/SLIDE 与耗散；
6. 能量审计、时间步减半和接触参数敏感性；
7. 保存结果与 M0 campaign 接口；
8. 少量解析/项目地形 smoke；
9. 用户审查后才允许重新设计正式 M2 筛选。

不能先跑大批量，再用输出反推模型是否合理。

## 六、生产 case 必需参数

正式 case 必须显式保存：

- 恒定外部预载和拖动速度；
- 安装座等效质量；
- 针体密度或轴向/横向模态质量；
- 各自由度阻尼；
- 接触法向刚度/阻尼或冲量模型；
- 摩擦正则化/粘着参数；
- 内部最大时间步、输出间距和积分容差。

缺少任一未能从已冻结硬件几何唯一推导的参数时，返回
`parameter_unclosed`，不得使用隐藏默认值生成正式排名。

## 七、路径和终止

初始时在持续外部预载下建立静态平衡，然后令
\(x_h(t)=x_h^0+v_{\rm drag}t\)。FREE 是正常时域状态；持续预载推动系统重新靠近
表面。普通脱离、旧准静态分支消失或短时零接触力都不得终止路径。

禁止生产路径使用：

- `fixed_holder_z_m`；
- `no_admissible_contact_equilibrium`；
- 拖动阶段 `preload_infeasible`；
- 将输出空间间距当作动力学积分步长。

## 八、输出和分析

必须保存时间、距离、位移、速度、加速度、外部载荷、接触/结构力、wrench、动能、
弹性能、接触储能、摩擦/阻尼耗散、能量残余和事件。

拉力必须使用全局拖拽方向的板面反力，不能用带符号局部切向分量冒充承载力。
稳态统计和冲击峰必须分开。

完成 100 mm 只是数据覆盖门禁。筛选重点是低分位拉力、接触占空比、再接触冲击、
结构裕度、能量与时间步收敛。

## 九、旧数据处置

旧 2700 个 fixed-Z case 及其摩擦/针径/刚度排名全部失效，只能保留为
`legacy_fixed_z_invalid_for_ranking` 诊断数据。不得据此淘汰 M3 候选。

## 十、交付物

1. 新动力学求解规格和数据字典；
2. M2 动力学代码与解析验收；
3. 旧 fixed-Z API/数据的失效标记；
4. M2→M3 动力学单元接口；
5. 少量代表性力—距离、Z—距离和接触状态图；
6. 未冻结物理参数清单；
7. 通过验收后再提出新的正式筛选计划。
