# IJMS 新版机理与接口

版本：0.5.0。正式路径入口：`spine_sim.ijms:run_case`。理论标识：`ijms-common-backplate-2026-09-10`。本页描述实际实现；批量配置、结果筛选及后续任务见 [批量仿真交接](IJMS批量仿真交接.md)。

## 理论依据与适用范围

主要依据为 `D:\Pdrive\Document\论文\IJMS\理论依据\共同背板轴向定向柔顺爪刺阵列_理论母稿.md`，并结合该目录的使用说明、仿真规划、实体实验规划及程序修改交接。通用最终母稿和 9.5 稿只采用与专用稿相容的部分。仓库原有 `docs/钩爪式爬壁机器人抓附机理与多尺度力学模型.md` 是旧理论存档。

共同背板刚性、三个转角固定，X 位移控制，Z 平衡恒定总法向载荷，Y 默认自由且总侧向力为零，也可显式锁定。模型采用光滑固定轴导向、无预压的独立压缩弹簧、有限回缩行程、孔外不可伸长且无材料扭转的弹性圆杆、理想球尖和固定表面。外部均布压力仅通过总载荷和装配参考点作用，逐刺载荷由求解获得。

只求单个球尖的单点接触；闭合多支撑、杆体与墙面碰撞和弹性许用值到界均停止当前路径并记录原因。它们不会被当成刺断裂或删除。没有真实动力回弹、材料破坏、墙面损伤、导向摩擦、针与针互碰、柔性背板或整机模型。三维高度场不能表示倒扣表面。

## 坐标与装配

背板实际平移为 `q=(X,Y,Z)`，+X 为拖动、+Z 为离墙方向。壁面对第 i 根针的力为 `f_i`：

\[
T=-\sum_i f_{ix},\quad P=\sum_i f_{iz},\quad L=\sum_i f_{iy},\quad N_i=f_i\cdot n_i.
\]

P_i 是宏观法向分量，N_i 是局部接触法向力，两者分别输出。T 可以为负。预载时斜针会产生切向反力，拖动时可能释放弹性能，均不截零。

`theta_deg` 是导向轴向下倾角；`yaw_deg=0` 时 `a=(cosθ,0,−sinθ)`。初始最外球面端点共面，`O_i^0=(x_i,y_i,r_i)`，`G_i=O_i^0−l0_i a_i`，实际导口是 `G_i+q`。网格间距指未变形针尖位置，不是导口间距。逐刺角度、长度、刚度、行程、直径和球半径均可覆盖。

`common_mouth_height_m=H` 改用共同导口高度装配，长度由 `(H−r_i)/sinθ_i` 求得，此时应省略显式 `free_length_m`。没有旧版 80°、4 mm 的隐含补偿规则。`loaded_area_m2` 是真实受压面积，不能仅凭零宽度的一行针推定。

## 可回缩空间杆

`guided_rod.GuidedRod` 的状态是 `[s/l0, β1,γ1,…,βm,γm]`。导口切线固定，后续节点有两个弯曲坐标。相邻单位切线以大圆弧连接，杆中心线是等弧长圆弧段，段长随 `l=l0−s` 更新。每段的中心线积分和弯曲能准确计算，段数控制连续杆近似误差。

\[
U=\tfrac12 k_s s^2 + \sum_j \frac{EI}{2h}\alpha_j^2,\qquad h=(l_0-s)/m.
\]

这里 α_j 为相邻单位切线夹角。端坐标、末端转动和能量来自同一构型；压缩导数含弯曲能随长度变化的项，保留移动边界配置力。没有仅将旧 `k_b` 换成 `3EI/(l0−s)^3`。

球面力在球心的力偶为 `τ=−r n×f`。广义平衡为

\[
R=U_u-J_O^T f-J_\omega^T\tau=0.
\]

端截面采用无材料扭转的平行搬运。针端可随弯曲转动，导口姿态始终固定。压缩方向导数解析计算，角度和切线使用中心差分；这是一套能量一致的离散杆，不声称默认三段已达到所有研究工况的精度。

上限位 `s=smax` 通过互补条件承担额外压缩反力，不采用惩罚大刚度，也不冻结弯曲自由度。默认 `lower_stop=false` 时，零压缩处仍要求轴向广义平衡，不能借下界承担拉力。只有显式 `lower_stop=true` 才允许伸出端挡肩反力。当前生产装配要求 `0<smax<l0`。

应力用当前实际中心线、球面力偶及沿杆位置到受力点的力臂计算，包含轴向、弯曲、横剪和扭矩的圆截面保守等效应力。空间最大值在采样截面上评估；杆段和应力采样误差需通过代表工况加密检查。缺少 `allowable_stress_Pa` 时只给应力，不伪造利用率或材料容量。

## 接触与路径

`continuous_geometry` 接受真实三维球心，返回连续三角高度场或无限平面的最近支撑点、物理单位法向和法向间隙 `g=有符号欧氏距离−r`。固定高度网格不再限制 X/Y 查询位置。三角网格缝的共面重复支撑被合并；真正近并列支撑保留，闭合时报告单点模型范围限制。

接触满足 `g≥0, N≥0, gN=0`。三维切向力通过库仑圆盘投影联立求解。材料点切向增量采用

\[
\Delta u_t=\Pi_t\{\Delta O+\log(R_{new}R_{old}^T)\times[-r\bar n]\}.
\]

它包含针端转动，不等于球心位移或墙面接触点位移。该式是有限步长离散，误差通过拖动步长细化控制。接触特征 ID 用于几何延续，不承担摩擦零位；已接受的杆构型、球心、端转动和力共同保存历史。持续滑动延续动摩擦支路，滑移停止后才允许恢复静摩擦支路。

流程是竖直接近至最早零力接触、递增建立目标 P、从完整预载状态开始拖动。外层控制物理路径和接受状态，内层稀疏最小二乘只求同一站的增广平衡。任何 Newton 中间值都不记为物理状态。

模式转换和明显的几何特征切换会缩步定位，再从前一已接受状态求有限重平衡。X/Y/Z 与杆内变量共同参与，逐刺力不预分配。初始等分载荷仅作为非线性求解器初值。

球心构型段进行扫掠胶囊检查，超过几何容差的中途阻挡要求缩步，不能从可行端点直接穿过凸峰。曲杆由真实圆弧加密采样并将弦弧误差加入胶囊半径，保守检测杆体碰撞。该做法验证离散构型段的几何可达性，不把它解释为真实动态回弹轨迹。最小步长下仍不能继续时保留已完成前缀，报告具体限制或数值失败。

## 全局求解与稳定性

每刺有局部杆变量及三个力变量，共同未知量只有 Y/Z（Y 锁定时只有 Z）。内变量保留于增广系统，有限差分按局部列分组，稀疏矩阵连接局部块与共同平衡行。默认在 CPU 执行，可通过原 runner 按 case 多进程并行；没有把局部活动集求解宣称为 GPU 加速。

`guided_stability.assess_stick_stability` 对光滑严格粘着支路在固定 X/转角下检查内部杆模态和允许 Y/Z 模态。它对含实际法向变化、预载及变长度的虚功残量求导，施加接触/限位约束，再逐刺凝聚。输出局部约束增量能量判据及矩阵不对称程度。滑动、摩擦边界、接触边界和不光滑几何单独报告，不能据此保证动态稳定。负的拖动力斜率不是本程序的失稳判据。

默认只在最后已接受状态做这项成本较高的检查；`solver.stability="off"` 可关闭，结果将明确标为未检查。逐站稳定性研究可直接调用该 Python 接口。

## 状态续算与实验接口

`output.level="full"` 的摘要包含 `continuation_state`。用 `PathState.from_snapshot(summary["continuation_state"])` 恢复完整材料运动历史，在相同装配、表面和机理版本的 `GuidedArray` 上调用 `solve(previous, x_m, preload_N)`，可以继续拖动或固定当前 X 求保持平衡。新的保持/方向加载实验可复用此状态；当前 JSON 协议只执行预载和沿 +X 拖动，尚未定义一般方向加载的控制规则。runner 的 `resume` 是按 case 恢复，不能替代此内部状态续算接口。

`research_protocols.SensorCalibration` 提供坐标旋转、力矩参考点移动、去皮和位移/时间零点映射。实测刚度、许用应力和摩擦可直接进入逐刺参数；导向摩擦与间隙只能先记录和标定，不能冒充理想导向模型已包含这些效应。各实体阶段与模拟输出的对应方法见批量交接。

## 本次验证与已测成本（2026-09-10）

完成 39 项新版相关测试，以及 4 项直接相关的旧版本身份、存储和恢复回归。验证覆盖球面接触、配置力、端矩、两向弯曲、无肩/限位、持续滑动/重新粘着、两刺分载、自由 Y、扫掠非穿透、指标和正式 SQLite 摘要恢复。分组 Jacobian 在异构两刺 18×18 系统上与逐列差分的最大差为 `2.97e−12`。
