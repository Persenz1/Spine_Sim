# 单刺与阵列统一仿真实施指导

## 1. 目标与规范边界

本轮直接在现有 `spine-sim` 仓库内完成一条可运行、可测试、唯一的生产链：

```text
terrain → geometry → single_spine → array
```

交付必须同时包含 `single_spine_quasistatic` 单刺准静态模型和
`array_rigid_backplate_event` 刚性共同背板阵列事件模型，不能停在接口、脚手架或设计文档。
这两个稳定字符串写入 `model_level`，不再用会与旧工程或理论章节冲突的 M1/M2/M3 名称。

整爪和整机不在本轮实现。单刺和阵列仍须输出坐标系、参考点、作用对象明确的
`Wrench` 与切线，使后续十字对爪、圆盘爪或其他内拉机构只组合阵列实例，不侵入局部求解器。

为控制上下文，建议按以下顺序阅读：

1. [`主稿修订审查`](../theory/2026-08-29_主稿修订审查.md)；
2. [`工程仿真参数继承表`](./工程仿真参数继承表.md)；
3. [`新版机理主稿`](../theory/raw/2026-08-28/钩爪式爬壁机器人抓附机理与多尺度力学模型.md)，
   重点第2–6、8–9、13章及附录C/D/F；
4. [`推导验算与冲突闭环`](../theory/raw/2026-08-28/推导验算与冲突闭环.md)；
5. 只有核对具体原式时才读取逐篇证据卡。

以上只是阅读顺序，不是规范优先级。发生物理/公式冲突时始终以“最新主稿 > 验算稿 > 证据卡”
为准；主稿修订审查是差异摘要，参数继承表是 legacy 输入映射，两者都不得覆盖主稿。

《钩爪抓附机理逐章讲义_大学水平离线版》不属于规范集，不审计、不归档、不引用，也不用于
裁决。旧需求和旧报告不定义新版物理或 API；其中的坐标/边界语义、候选参数轴和已运行 preset
由《工程仿真参数继承表》分类迁移。只有明确语义与历史 preset identity 被锁定，候选值不得
升格为定型硬件，legacy 回归值不得升格为已标定材料参数。

## 2. 已冻结的工程决策

- 只维护一套程序。与新版机理冲突的旧实现直接替换，不创建 `v2`、legacy physics solver、
  双状态机、双 schema 写入或从新求解器自动退回旧物理核的 fallback。
- 上述禁令不影响有明确用途的 I/O 降级、terrain `auto` 选择和现有可选 CPU/CUDA 地形后端；
  它只禁止两套物理语义并存。单刺和阵列的权威数值实现是 CPU，本轮不新增 CUDA 依赖。
- 不下载砂纸扫描，不生成正式300地形，不运行大 campaign。解析面和小型合成地形足够验收。
- 无损迁移原工程的坐标/边界语义、针尖/针杆/长度/角度候选域、阵列候选域、单边弹簧规则、
  加载 protocol 及已运行设计输入。先建 canonical parameter registry 和逐字段迁移测试，再删除
  旧路径；迁移保持候选/preset 的数值与身份，不把它们冒充唯一硬件定型。
- canonical config/result 的角度一律用 rad。旧 `α` 是朝墙为正的安装角，主稿 `β` 是 pitch、
  `ψ` 是 yaw：canonical 字段映射为 `pitch_rad=-deg2rad(alpha_old_deg)`、
  `yaw_rad=deg2rad(beta_yaw_old_deg)=0`。角度梯度保持原 x 列顺序，不得因符号转换反转实体
  布局；degree 仅存在于 legacy importer/展示层。
- 每个结果必须保存 `model_level`、假设、遗漏、参数来源、适用范围和不能回答的问题。
  只有当前 model level 或显式请求分支实际消费却缺失的参数才是 `PARAMETER_UNCLOSED`；本轮
  明确不求解的动态/损伤能力记 assumptions/omissions 与 `OUT_OF_SCOPE`。两者都不得填无来源
  默认值，也不得伪装成物理失效或数值失败。
- 保留 `core/io/runtime`、地形生成/库/有限尖包络、trial/accepted 隔离及可复用的批处理思想；
  不保留旧物理核的冲突语义。`J+ / J- / Jnet` 的公式保存在仓库旧报告而不在当前源码，需按
  第4.4节定义重新实现并加测试，不能声称从旧 solver 直接迁移。

## 3. Terrain → geometry 合同

### 3.1 保留与修复

保留材料随机场、解析/实测高度场、`TerrainLibrary`、有限球尖可达包络及现有 CPU/CUDA
地形对照算法。现有二维包络已能输出 x/y 坡度、support x/y、valid 和 near-tie，且已有
`forward_cap_gate` 与 `check_rod_clearance`；因此不重写地形生成器。
同时保留参数表中的材料 validation status/provenance：P40/P100/P240 只是单公开样本部分验证，
其余砂纸及 red_brick/concrete 仍为 provisional，不得因进入新版 solver 被改称已标定材料。

必须修复下游合同：

1. 停止使用 `m3_fast/terrain.py` 只传 x、包络高度、x 坡度和 valid 的降质路径。
2. `TerrainLibrary.cache_track` 传播材料 `valid_mask`。一个有限球尖候选只有在整个针尖 footprint
   所需的源表面区域都有效时才可判为确定有效，不能只检查获胜 support；footprint 覆盖未知区时
   必须标为不确定/无效，不能用有限占位高度冒充真实表面。
3. 实测表面按主稿式(4-21a)保留探针元数据、唯一/多解判据、测量容差、确定/不确定掩膜和
   上下几何界。未知探针就是不确定输入；没有扫描数据时不得伪造探针、掩膜或界。
4. 缓存语义变化时同步提升 `_TRACK_SCHEMA`、`ENVELOPE_ALGORITHM_VERSION`、track identity 和
   数据字典。旧缓存可重建，直接要求重建，不做双读兼容。

### 3.2 `ContactCandidate`

统一候选至少包含：

- 稳定 `candidate_id`/lineage、terrain/track/geometry 版本、候选序号、沿路径距离、来源 feature；
- 针尖中心、support 集/接触点、signed gap、局部曲率或等效半径；无法确定时显式 unknown；
- `surface_normal`、`envelope_normal` 和球面径向 `contact_normal`，以及说明本构实际采用哪一种的
  `normal_model`；三者不得混名；
- 单位切向基、valid、near-tie/support-set、几何与测量不确定性及上下界；
- 与候选和针轴方向共同计算的 forward-cap 结果；由完整针姿态、杆轴和杆径计算的 rod-clearance，
  后者不能伪装成与针姿态无关的 terrain 常量；
- 下一候选的 search cursor/query queue，使拒绝、脱离和回弹后可沿同一条路径继续搜索。

near-tie 或多 support 时保留候选集合/不确定性，禁止强压成唯一物理法向。support 身份跨切换点
不能线性插值；应局部重查 support 或按分段身份定位切换事件。三维接触只使用选定法向投影和
摩擦锥，不再叠加独立角度约束。

提供唯一查询接口，例如：

```text
query_next_candidate(surface_state, spine_path, cursor, spine_pose)
```

并提供唯一 canonical 路径延拓驱动。SEARCH、拒绝候选、脱离、回弹后恢复搜索资格、单次运行、
campaign 和 `J` 指标都调用它，禁止各自复制 `0,+dx,-dx...` 或另一套候选遍历逻辑。

## 4. 唯一物理合同

### 4.1 状态、事件与失败维度

`core/states.py` 统一物理八态：

```text
SEARCH, CONTACT, STICK, SLIP, DETACH, REBOUND, HARDSTOP, FAILED
```

`CONTACT` 是瞬时合法性判定，不是长期驻留本构。每根刺独立保存 search cursor、接触、回弹和
损伤历史；不得以全阵列清空代替。统一 `EventType`：

```text
CONTACT, CONTACT_REJECT, STICK_START, SLIP_START, RESTICK, DETACH,
REBOUND_START, REBOUND_COMPLETE, REENGAGE,
HARDSTOP, HARDSTOP_RELEASE, MATERIAL_FAILURE
```

合法转换固定为：

| EventType | from → to / 动作 |
|---|---|
| `CONTACT` | `SEARCH→CONTACT`，仅用于没有既往脱离循环的首次/新候选接触 |
| `CONTACT_REJECT` | `CONTACT→SEARCH`；候选要求负法向力、几何/门控不合法或接触相容失败时在同站拒绝并推进该刺 cursor；不经过 DETACH/REBOUND，也不增加 `reengagement_count` |
| `REENGAGE` | `SEARCH→CONTACT`，仅用于该刺已完成至少一次 detach/rebound/search 循环；只有随后解析为承载接触并 commit 时才增加 `reengagement_count` |
| `STICK_START` | `CONTACT→STICK` |
| `SLIP_START` | `CONTACT/STICK→SLIP` |
| `RESTICK` | `SLIP→STICK` |
| `DETACH` | `CONTACT/STICK/SLIP/HARDSTOP→DETACH` |
| `REBOUND_START` | `DETACH→REBOUND` |
| `REBOUND_COMPLETE` | `REBOUND→SEARCH` |
| `HARDSTOP` | `CONTACT/STICK/SLIP→HARDSTOP`；payload 保存进入前 contact mode |
| `HARDSTOP_RELEASE` | `HARDSTOP→CONTACT`，随后在同一事件位置解析为 STICK/SLIP/DETACH |
| `MATERIAL_FAILURE` | 按第4.2节的 failure action 进入吸收态 `FAILED` 或在模型边界停止 continuation |

`FAILED` 在本轮是吸收态。非法 from/to 不得靠强制赋值继续运行。
`CONTACT/REENGAGE` 在瞬时合法性判定完成前只是 trial proposal；若随后
`CONTACT_REJECT`，不得提交接触历史或再挂接计数。

步长缩小、牛顿重试、活动集重算等数值事件与上述物理事件分表记录。物理、数值、模型和运行
状态继续分维；模型状态至少含精确枚举 `CLOSED`、`PARAMETER_UNCLOSED`、`OUT_OF_SCOPE`。
轴向安装/弹簧分支统一为 `RIGID/LOWER_STOP/INTERIOR/HARDSTOP`，不再混用 `HARD_STOP` 拼写；
处于物理 `HARDSTOP` 时仍须保存 STICK/SLIP contact submode，不能丢失摩擦状态。
删除本地裸整数 `FREE/STICK/SLIDE` 的生产语义，不保留别名兼容层。

### 4.2 Canonical 单刺

`solve_single_spine` 接收单刺几何、材料、摩擦、悬架、有限行程、已接受状态、基座运动和
`ContactCandidate`。trial 只能写 workspace；收敛且事件处理完成后才能 commit。首个生产基线是
三维点接触库仑摩擦锥、线弹性梁或明确的低阶悬架、准静态加载、有限行程和硬限位；第2章二维
楔块是它的解析特例，不是第二套 solver。

输出至少包括：

- 墙对针接触力、针传给背板的根部 `Wrench`，以及坐标系、参考点和作用对象；
- 状态、接触点/局部基、变形、反力，固定光滑分支上的局部力切线与根部 wrench 切线；
- 摩擦、针杆、Hertz、表面、通道和行程各分支的利用率/安全裕度；
- 平衡/互补残差、下一物理事件及参数/模型闭合状态。

结构强度、Hertz 与表面/断裂容量只在参数闭合时返回确定值。拓扑含针—管或杆身接触却缺少
标定时返回 `PARAMETER_UNCLOSED`；该拓扑不存在时返回 `OUT_OF_SCOPE`。不得沿用无来源的
`C_i,c_i`，不得把理想力场代替真实悬架本构，也不得给三维摩擦锥另加经验角度门槛。

`MATERIAL_FAILURE` 必须携带 `failure_object`、`failure_mode`、criterion/demand/capacity/margin、
参数来源和 `continuation_action`。本轮只允许两种后处理：

- `PERMANENT_REMOVE`：仅用于参数闭合且明确建模为整根刺/根部灾难性断开的模式；该刺进入
  吸收态 `FAILED`、力置零、退出活动集，阵列才可继续事件后重平衡。
- `STOP_MODEL_LIMIT`：屈服后的塑性、针尖钝化/断裂后新几何、峰体剥落、通道损伤或微损伤等
  需要演化律的模式，在首次边界处停止确定 continuation。边界前结果有效，后续标为
  `OUT_OF_SCOPE`；不得擅自删除接触、更新地形或继续外推。

若判定 failure 本身所需参数缺失，则是 `PARAMETER_UNCLOSED`，不得伪造 `MATERIAL_FAILURE`。
因此阵列步骤中的“删除失效刺并级联”只适用于 payload 明确为 `PERMANENT_REMOVE` 的事件。

真实动态回弹在本轮显式降级为准静态恢复资格规则：记录所用位移/距离阈值与遗漏的时间尺度，
不在同一站无条件瞬时重接触，更不能用指数正距离支路的无记忆性证明全局 reset。

弹簧支路必须把互补条件求闭合，不能选支路后只重算一次。固定回归夹具为：

- `h(x)=A sin(2πx/λ)`，`A=0.229183118 mm`、`λ=0.8 mm`；x 网格 `[-10,15] mm`、
  `dx=0.1 mm`，路径从0开始，station 0 的针尖 x 为2 mm；全域 valid，无邻近 landing；
- 针长4 mm、针杆直径 `d=0.8 mm`、安装角60°、针尖半径50 μm；
- `E=200 GPa`、`ν=0.29`、剪切修正 `κ=6/7`、`μs=0.45`、`μk=0.35`；
- 弹簧 `k=300 N/m`、行程4 mm、法向预载0.5 N、旧 solver 的 z 求根区间宽度6 mm；初态
  映射为 `SEARCH`。该6 mm 仅固定回归数值 bracket，不是已证实的背板机械行程。

旧核错误返回 `Fx=+0.444785 N`、`Fz=0.5 N`、弹簧轴向力 `0.210620 N` 却选择
`LOWER_STOP`。正确分支为 `INTERIOR`，`u=0.210620/300=0.702067 mm < 4 mm`。
该夹具只闭合轴向弹簧互补与旧2D力学子问题，不表示材料容量、表面、通道或整个单刺 case
已经 `CLOSED`。

### 4.3 Canonical 阵列与混合控制

`solve_array_equilibrium` 只调用 canonical 单刺本构，不复制局部闭式。输入包括任意逐刺位置、
姿态、独立初始间隙 `d_i^0`、逐刺已接受状态、刚性共同背板、required wrench、加载器刚度和
自由度合同；`d_i^0` 与当前 terrain signed gap 是不同量。

统一使用相对加载广义坐标 `q_C`。固定墙面时，背板实际小位姿增量定义为 `-q_C`。每个6D
分量必须且只能选择以下一种：

1. prescribed pose；或
2. required generalized force/moment residual，并可带 loader stiffness。

同一分量不能既规定位置又要求独立力残差。力与力矩残差用显式参考力 `F_ref` 和参考长度
`L_ref` 无量纲化后再判收敛、秩和值域；秩容差作用于尺度化系统。伪逆只能生成诊断/试探方向，
不能把不相容或秩亏系统记为成功。标量 z 是这一个求解器的边界条件特例。

一个增量依次执行：预测活动集；在允许自由子空间求平衡；加入闭合候选并删除负法向接触；
检查摩擦、容量和限位；在步内定位最早事件；只更新到达事件的刺；按主稿式(9-29)用释放力和
释放力矩预测事件后状态；在同一载荷参数重平衡；重复级联直至满足下述平衡/稳定性状态合同或
返回明确边界。逐站局部装配
应为 O(N)，只允许对背板广义自由度形成小型稠密矩阵，禁止构造或求解 N×N 稠密耦合矩阵。

“平衡可解”和“稳定”分开判定。令 `K_T` 为包含 loader、当前一致切线及本 model level 所含
几何刚度的总广义切线；用广义坐标尺度 `D_q=diag(L_ref,L_ref,L_ref,1,1,1)` 和能量尺度
`F_ref*L_ref` 构造无量纲能量切线：

```text
K_hat = D_q.T @ K_T @ D_q / (F_ref*L_ref)
```

对全 STICK/保守分支（含保存 STICK submode 的 HARDSTOP），在 active equality 约束的尺度化
自由子空间基 `Z` 上取
`K_red=Z.T @ sym(K_hat) @ Z`。令
`tau_stab=stability_abs_tol+stability_rel_tol*||K_red||_2`：

- `lambda_min(K_red)>tau_stab` 才是 `STABLE_CONSERVATIVE`；
- `|lambda_min|<=tau_stab` 是 `MARGINAL_CONSERVATIVE`，定位为边界，不宣称稳定后状态；
- `lambda_min<-tau_stab` 是 `UNSTABLE_CONSERVATIVE`，属于物理不稳定而非数值失败；
- 自由子空间维数为0时记 `NO_FREE_MODE`，只表示运动学约束下无可检验扰动模态。

SLIP 或其他非对称/非保守切线不能用 `sym(K)` 正定冒充动态稳定。本轮无质量/阻尼时，只可在
尺度化增量系统唯一可解、值域相容、正向试探增量满足一侧摩擦/接触/限位条件且残差收敛时标记
`DIRECTIONALLY_ADMISSIBLE_QUASISTATIC`；同时保存 `dynamic_stability=OUT_OF_SCOPE`，不得输出
“stable=true”。事件级联只有在保守分支达到 `STABLE_CONSERVATIVE/NO_FREE_MODE`，或在明确的
准静态降级下达到上述 directional status，才算本增量完成。秩、值域、残差和稳定性字段必须
分别保存；缺少几何刚度时也须列入 assumptions。

### 4.4 指标的唯一口径

一个公共谓词模块定义并被 trace、summary 和报告共用：

- `n_nominal`：输入阵列中的总刺数；
- `n_geometric`：当前路径/姿态下存在有效几何候选的刺数；
- `n_contact`：有效候选在事件处理后满足 `signed_gap<=gap_tolerance` 的刺数；按主稿式(9-12)
  选择“闭合即计入”，因此事件瞬间闭合但零法向力仍计入；
- `n_engaged`：稳定挂接集合大小，严格对应理论 `n_e=|E|`；接触还须满足摩擦可行、局部滑移
  方向不会立即离开安全坡面，且结构状态没有触发脱离；
- `n_active`：当前承载活动集大小，严格对应理论 `n_eff=|A|`。

参数/模型是否足以判断稳定挂接是认识状态，不是物理 `n_e`。另设 `n_evaluable` 统计挂接谓词
可判定的刺数。未知不得按 false 计入：若有不可评估项，`n_engaged` 标量为 null，同时输出
`n_engaged_lower`（确定为 true）和 `n_engaged_upper`（true+unknown）；只有全部可评估时才输出
确定 `n_engaged`。模型闭合状态另行保存，不再使用含混的 `n_engageable`。
这里的 stable engagement 是逐刺局部安全坡面/不脱离谓词，不替代第4.3节的阵列自由子空间
稳定性检查。

对每个计入 `n_contact` 的接触，以本构使用的局部接触法向定义非负标量法向反力 `N_i`；瞬时
闭合零力项取 `N_i=0`：
`P_sum=ΣN_i`，且仅在 `n_contact>0` 时定义 `P_avg=P_sum/n_contact`。若另需统一墙法向投影，
必须另名并保存所用 `n_ref`，不得混入 `P_sum`。

`J` 指标按仓库内 [`旧母稿第3.2节`](../archive/legacy_simulation_evidence/M3_共同背板微刺阵列机理与仿真母稿.md)
的定义重实现。对外部总法向预载 `P_ext>0`、规定抗拖正方向反力 `F_x(x)` 和完整有效路径长度
`L`，令 `f(x)=F_x(x)/P_ext`：

```text
J+   = (1/L) ∫ max( f(x), 0) dx
J-   = (1/L) ∫ max(-f(x), 0) dx
Jnet = J+ - J-
```

只对 accepted 且 valid 的连续路径积分并报告有效长度/覆盖率；missing/invalid 不补零，也不跨
缺口连接积分。若合同允许聚合多个有效连续段，分子积分与分母有效长度须按同一段集合计算。
旧 `Fx/P>=0.25`、0.50 mm 稳定窗、0.25 mm 灵敏度窗和 `duty25` 仅作为命名
`legacy_analysis` preset，不得进入接触/事件判据或 canonical solver。

旧 inverse-Simpson 指标改名为 `n_share_normal`、`n_share_tangent_positive`；理论共享指标使用
`load_sharing_index`。`reengagement_count` 只统计真实的逐刺状态循环。任何旧 `Neff` 字段都不得
继续承载两种含义。

## 5. 迁移、CLI 与结果身份

`m3_fast` 只迁移有明确调用价值的能力：小型 canonical run/campaign、严格配对 seed、
Parquet manifest/trace，以及 coarse/fine/final 的渐进采样概念。不要整段搬运旧约2200行流程、
旧排名逻辑或旧物理假设。使用临时解析地形目录完成 CLI、campaign 和 schema I/O smoke；它不是
正式300地形。旧 monitor 若能改名并验证新语义则迁移，否则删除。

物理参数不是可选的“旧流程能力”。《工程仿真参数继承表》中的完整设计空间、已运行 protocol、
12个终筛 legacy design ID 与逐字段 SI 值必须先迁到 canonical registry；原 ID 仅作 provenance，
新版 case/result identity 仍按新版本产生。新版物理可以改变这些构型的响应和排序，但不能静默
改变它们代表的实体输入。

仿真生产入口从 `spine-m3-fast` 迁到 `spine-sim`；独立地形工具 `spine-terrain` 继续保留。
生产包按职责使用 `geometry / single_spine / array`。提升 project/model/result schema 与 solver
semantics version；case/result identity 必须包含这些版本、terrain/geometry 版本和规范化输入哈希。
新结果不得覆盖旧结果。结果数据字典同步更新。

只有在等价的新语义测试、canonical campaign smoke 和 schema round-trip 已覆盖相应能力后，
才删除旧 model/solver/terrain 消费路径、独立入口、本地状态常量、全局 reseat、旧 `Neff`、
只验证旧语义的测试和 monitor。历史结果由 Git/Pdrive 证据解释，不需要可运行旧程序。

## 6. 实施顺序

在同一个窗口连续完成，不在单刺和阵列之间再次停下来询问架构：

1. 跑现有小测试并记录基线；审计 terrain→geometry，落实第3节最小 schema 修复。
2. 先落地 canonical parameter registry 与旧配置逐字段迁移测试，再建立统一状态、事件、
   candidate/query/result、坐标、单位、作用对象和参数来源合同。
3. 实现 canonical 单刺本构、容量、互补、trial/commit、路径延拓和解析测试。
4. 实现统一6D/active-DOF 阵列平衡、活动集、事件后重分配和逐刺再挂接。
5. 迁移第5节限定的 campaign/trace/指标，更新 CLI、公开 API、版本、README 和数据字典。
6. 等价覆盖建立后删除旧生产路径，运行全部可用测试。不要启动正式材料 campaign。

## 7. 验收门禁

### Geometry

- 平面、正弦面、窄谷的有限尖可达、support、候选顺序、首次遭遇和三类法向语义正确；
- footprint-valid、实测上下界、support switch、near-tie、forward-cap 和 pose-aware rod-clearance
  不丢失；没有扫描数据时，不确定性字段诚实为空/不适用；
- cache/version/identity 变化可检测，原 terrain 生成测试不退化。

### Single spine

- 第2章二维楔块闭式、零/普通摩擦、绝对自锁、剥离和双向滑移符号通过；
- `N>=0`、三维摩擦锥、有限行程和弹簧分支互补通过，0.702067 mm 固定夹具通过；
- 梁悬臂、Hertz、表面容量、条件式缺参分类和 wrench 搬移通过；
- 闭合的灾难性断开进入永久删除；塑性/钝化/剥落等首界停止，failure payload 与 continuation
  action 可复现，缺参时不伪造 failure；
- 八态转换不可越级，含 CONTACT_REJECT、SLIP→RESTICK 和 HARDSTOP_RELEASE；非法候选不触发
  detach/rebound/reengagement；最早事件随步长减半收敛，拒绝 trial 不污染 accepted；
- 一致切线的中心有限差分只在固定光滑分支/活动集上验证；事件边界用前后单边值和跳变测试，
  不把不连续点伪装成可微。

### Array

- `n=1` 严格退化为 canonical 单刺；相同间隙/刚度完全均载；`d_i^0` 异常按阈值参与；
- 第8/9章两刺力控、位移控和有限加载刚度闭式通过，`q_C` 符号与混合控制互斥合同通过；
- 单刺失效后力与力矩守恒并按式(9-29)重分配；尺度化秩亏/值域不相容不得伪成功；
- 保守分支的约束自由子空间正/零/负特征值夹具分别得到 stable/marginal/unstable；SLIP 非对称
  切线不得用对称特征值宣称动态稳定，只能得到明确 directional quasistatic 状态；
- 任意位置/姿态和 active DOF mask 可用；一根刺的事件不清空其他刺历史；
- 脱离—回弹/恢复搜索资格—再挂接、事件级联及全部计数/载荷指标边界通过；稳定挂接 `n_e`
  与 `n_evaluable` 分离，未知项输出上下界而非按 false；
- 400–3600 刺解析布局 smoke 不构造 N×N 稠密矩阵，局部装配和内存随 N 近似线性。

### 工程完成

- 临时解析 catalog 上，`spine-sim` 单次运行、paired-seed 小 campaign、manifest/trace Parquet
  或明确 I/O 降级、schema round-trip 均通过；`spine-terrain` 保持可用；
- canonical registry 可表达原工程候选参数轴而不自动执行全笛卡尔积，并精确生成命名 protocol、
  已运行子集和12个终筛 preset；配置/单位/identity 迁移报告无未解释差异；
- 结果保存 units、frames、作用对象、版本/identity、parameter provenance、model_level、
  assumptions/omissions、残差/容差、秩/值域/稳定性状态及逐刺状态、几何、wrench、margins、
  events；
- 物理、数值、模型和运行失败分开；旧数据只做选定趋势/量级回归，不逐点拟合；
- 全部可用测试通过；生产源码/entrypoint 不再引用 `m3_fast`、全局 reseat 或旧 `Neff`；
- 没有第二套物理核、双 schema 写入、未注明经验默认参数，也没有把真实动态回弹、损伤演化、
