# 工程仿真参数继承表

## 1. 用途与优先级

新版机理重构允许替换旧求解算法和状态语义，不允许丢失原工程的坐标/边界语义、候选设计域
或已运行 preset 的物理输入。参数裁决按
以下优先级执行：

1. 用户明确的新决定；
2. 新版机理对参数含义、坐标和适用条件的约束；
3. 旧执行版的“固定工程背景”与实际运行过的配置/manifest；
4. 代码默认值；
5. 数值调参值。

其中第3项只对装置、加载协议和已经执行的设计点有权威性，不让旧物理核反向覆盖新版机理。
原工程参数足以定义旧二维筛选的候选空间与运行 protocol，但不等于已经完成材料标定、选定唯一
样机或闭合三维/整爪全部参数。新版必须完整继承前者，也必须诚实保留后者的未闭合状态。
主要证据为：

- [`旧执行版第2章`](../archive/legacy_requirements/爪刺耦合仿真器_工程背景_理论边界与实现指导_执行版.md)；
- [`历史终筛输入`](../archive/legacy_simulation_evidence/manifests/terminal_input_selected_designs.json)；
- `src/spine_sim/m3_fast/model.py` 与 `campaign.py` 中的当前默认、已执行 full-scan 轴域及仅由
  generator 定义的候选集合；三者按证据状态分开。

新实现应建立一个 machine-readable canonical parameter registry，并由测试锁定本表。每个字段
至少标记 `frozen_design_semantics`、`candidate_design_value`、`legacy_regression`、
`numerical_protocol`、`legacy_analysis` 或 `unclosed` 之一。所有配置集中从 registry/typed
config 产生；不得在
solver、campaign、CLI 和测试中各藏一套默认值。

表内角度为便于核对旧资料而用度数展示；canonical config/result 一律使用 SI 弧度字段。旧配置
的 `*_deg` 只允许出现在 importer/展示层，进入 registry 前立即、显式转换为 `*_rad`。

角度梯度的原始设计包含沿局部 x 的 80°→50°、80°→60°；实际已运行的全扫描和终筛另有
60°→80°。三者是方向不同的物理布局，均不得用模糊 `gradient` 合并。新 schema 保存
`pitch_by_x_column_rad` 或明确 `pitch_at_x_min_rad/pitch_at_x_max_rad`。迁移历史
`60_to_80` 时保持原 x 列顺序，并转换成 canonical pitch `-60°→-80°`（以 rad 存储）；不得为了
统一命名而反转实体布局。

预载在整条路径持续施加；恒定的是外部执行器载荷，不是每个接触点、每根刺或每个时刻的
接触反力。新版准静态模型是明确降级：它可以求连续平衡分支和事件后重平衡，不能声称已经
实现旧执行版设想的时域冲击与动态回弹。

### 4.1 地形材料参数状态

地形数值继续沿用，但材料名称不等于完成标定。P40/P100/P240 各只用一个公开 Hirox 高程样本
做了部分验证，状态是 `partially_validated`，不能代表该粒度总体；其他无实测砂纸子型为
`provisional`，其中 P200 是 P180–P240 间插值，P300 是 P240 外推。red_brick/concrete 参数是
工程先验，仍为 `provisional`。证据见
[`材料地形实现状态`](../research/terrain/03_material_generation_implementation.md) 与
[`M1 未闭合问题`](../m1/M1_OPEN_ISSUES.md)。

本机没有项目自己的砂纸原始扫描，本轮也不下载；这不阻塞解析/合成地形上的单刺和阵列实现。
registry/result 必须保存 material recipe、subtype、版本、validation status 和 provenance，禁止将
合成 profile 名称写成“已实测标定材料”。

## 6. 既有材料/摩擦基线与数值协议

当前实际程序使用 `E=200 GPa`、`ν=0.29`、剪切修正 `κ=6/7`、`μs=0.45`、`μk=0.35`。
这些值在迁移后的命名工程回归配置中保持不变，但必须标记为 `legacy_regression`，不能成为
无来源的全局 canonical 默认，也不能写成已完成高碳钢牌号或墙面摩擦标定。若新版机理需要额外
材料、Hertz、断裂、通道或杆身参数，缺参就返回 `PARAMETER_UNCLOSED`，不能借沿用本组值补齐。

旧 fast 路径的 `dx=0.1 mm`、10 mm 路径、力残差容差和迭代上限属于数值/smoke protocol，
不是装置尺寸。新求解器可以在收敛证据下调整它们，但必须：

1. 用命名 protocol 保存旧值，支持严格配置/单位/identity round-trip 回归，不要求复现旧物理响应；
2. 把新容差、尺度和步长写入 result identity；
3. 不改变上述物理几何、加载和已运行设计点；
4. 对任何参数变化输出逐字段 migration report，而不是静默套用新默认值。

旧数值核还固定 `contact_clearance=1e-12 m`、全局邻落点5步、最多3次 Newton 修正、6次区间
评估、9次 station evaluation，以及 `max(0.01 N, 0.01×preload)` 力容差。这些只进入旧结果
复现信息：全局邻落点逻辑必须删除，其余容差/预算由新版尺度化残差和收敛试验重新确定。

旧 `Fx/P>=0.25`、0.50 mm 稳定窗、0.25 mm 灵敏度窗、`duty25` 等属于
`legacy_analysis`，不是装置参数、接触判据或物理事件阈值。旧数据合同曾将未接受站补成零力；
该做法不得进入 canonical trace，新分析必须区分 accepted/valid、missing 和 invalid。

现有资料尚未给出可作为确定输入的钢牌号/强度/疲劳、表面弹性与断裂参数、球冠—锥段完整
尺寸、针—管间隙与摩擦、逐刺装配初始间隙 `d_i^0`、三维装配误差、真实悬架耦合/滞回、质量、
阻尼和动态回弹参数。只有当前 model level 实际消费的参数才进入本轮 typed config：例如 case
要求某容量或装配间隙却缺值时返回 `PARAMETER_UNCLOSED`。质量、阻尼、真实动态回弹、损伤演化
等已被准静态 model level 明确排除的能力写入 assumptions/omissions 并报告 `OUT_OF_SCOPE`，
不作为本轮必填字段，也不能使正常准静态结果永远“未闭合”。不得从旧2D响应、终筛排名或测试
夹具反推填充任何缺值。

## 7. 迁移验收

- canonical registry 能表达单刺/阵列全部候选参数轴而不自动执行全笛卡尔积，并能精确生成各
  命名 protocol、已运行筛选子集和12个终筛 preset；
- 新旧配置对共同字段做逐字段 SI 对比；旧 degree/朝墙正角经上述映射后，针轴向量与 x 列顺序
  必须相同，不能只比较未换单位/未换符号的角度标量；rigid/finite spring 语义一致；
- 配置 round-trip 与 case identity 测试覆盖参数来源和 protocol 名；
- 删除 `m3_fast` 前，所有物理装置参数和历史 design ID 已作为 provenance 迁入新配置，不依赖
  旧模块才能读取，也不与新版 case/result identity 混用；
- 未经用户或新证据明确批准，不改变物理装置数值；若新机理使某参数含义不再成立，标为冲突并
  停用该派生量，而不是擅自改成另一个数值。
