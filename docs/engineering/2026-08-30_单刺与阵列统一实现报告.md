## 2. 工程参数迁移

单一 registry 为 `src/spine_sim/parameters/registry.json`。保留并分类了：

- 墙面/单元坐标、轴向与 wrench 作用对象/参考点语义；
- 针尖半径 50/100 μm、杆径 0.6/0.8 mm；
- 固定 `L_e=4 mm`，梯度 `L_j=4 sin80°/sinα_j mm`；
- 固定旧角 50/60/70/80°，按 `pitch_rad=-deg2rad(alpha_old_deg)` 迁移为负弧度，`yaw_rad=0`；旧 60→80° 列顺序未翻转；
- `nx,ny∈{2,3,4,5,6}`、4/5/6 mm 间距；
- rigid 或逐刺单边弹簧、100–2000 N/m 候选范围、4 mm 行程；
- 0.5 N 单刺与 0.5/1/2 N 阵列持续外部预载、+X 拖拽、1 mm/s、最大 100 mm；
- 10/5 μm 数值 protocol、paired seeds、coarse/fine/final 身份及历史十字对爪参数；
- machine final `C6/A3/A4/C5/C2/C7` 与人工 `A1/A2/A3/A5`（第五 A4）分别保存，不合并成定型样机。

M3-A 80、M3-B 28、full scan 1344 个 source-defined/legacy generator 与全部 legacy ID
已按原顺序逐项对照；12 个终筛 design/role round-trip 通过。逐字段 migration report 的
`unexplained_differences=()`。有意差异只有 schema 名称、SI 单位、degree→rad、rigid tagged union
和新版 versioned identity；旧 ID 仅作 provenance。旧 `E=200 GPa, ν=0.29, κ=6/7,
μs=0.45, μk=0.35` 只存在于命名 `legacy_regression`，不是全局默认。

## 3. Terrain → geometry 修改

- Track 升为 schema 2 / `finite-sphere-envelope-v2-footprint-support2`。
- identity 纳入 tie tolerance、raw height/mask hash 和 measurement semantics hash；v1 cache 明确要求重建，无双读。
- 完整球 footprint valid 会传播非 winner 的 invalid；保存 top-2 support、feature switch、x/y slope、surface/envelope/contact normal。
- 实测 mask、probe/tolerance、上下界和 geometry uncertainty 进入 cache 与候选；缺数据显式 null/unknown。
- 新增唯一 `ContactCandidate`、`CandidateCursor`、`query_next_candidate` 和 path driver；support switch 不插值、near-tie 不强选法向。
- forward-cap 与完整姿态球冠—锥段—圆柱杆 clearance 已接入；一般 mesh 为 `OUT_OF_SCOPE`。

材料算法、CPU/CUDA terrain 后端和 `TerrainLibrary` 保留。没有下载新扫描；P40/P100/P240
单样本仍仅 `partially_validated`，其余砂纸及砖/混凝土仍为 `provisional`。

## 4. Canonical 单刺

- 八态与冻结 EventType、非法转换验证、逐刺 accepted/trial/commit 历史。
- 二维有符号楔形闭式与三维点接触摩擦锥、双向滑移/再粘着。
- Timoshenko 低阶梁/附加悬架柔顺、单边轴向弹簧、硬限位与释放。
- Wrench 参考点/作用对象、一致切线、最早事件定位和单边跳变。
- 针杆、Hertz、表面和断裂条件容量；缺参为 `PARAMETER_UNCLOSED`，拓扑不存在为
  `OUT_OF_SCOPE`。只有闭合灾难性断开可永久删除，损伤演化需求在首界停止。
- 固定轴向弹簧夹具得到 `INTERIOR` 和 `u=0.702067 mm`；未把该子问题扩大成整 case 闭合。

## 5. Canonical 阵列

- 只调用 canonical 单刺，支持逐刺位置/姿态/`d_i0`、候选序列和独立 cursor。
- 6D `q_C` 与固定墙面实际位姿 `-q_C`，逐分量 pose/wrench 互斥控制、loader stiffness 和 equality constraints。
- O(N) 局部装配，只形成最多 6×6 稠密矩阵；3600 刺门禁通过。
- 尺度化残差、rank/range 独立判定；不以伪逆宣称成功。
- 全局最早事件按 `(load_parameter,event_fraction)` 选择，只推进最早并列刺后同载荷重平衡。
- 永久失败不复活；释放力/力矩 ledger 与式 (9-29) predictor 保存，随后由非线性残差复核。
- 保守分支按约束自由子空间无量纲能量切线判 stable/marginal/unstable/no-free。
- SLIP 及 HARDSTOP-SLIP 不做对称正定冒充，仅在当前分支耗散、接触/摩擦/限位互补和局部数值状态闭合时给 `DIRECTIONALLY_ADMISSIBLE_QUASISTATIC`；dynamic stability 恒为 `OUT_OF_SCOPE`。

## 6. 指标与结果

公共谓词集中定义 `n_nominal/n_geometric/n_contact/n_engaged/n_active`；
`n_evaluable` 和 engaged 上下界与物理计数分离。`P_sum/P_avg` 使用局部法向反力，零接触平均值为 null。
inverse-Simpson 已改名 `n_share_normal/n_share_tangent_positive`，另保存理论
`load_sharing_index`。`J+/J-/Jnet` 只跨相邻 accepted+valid 区间，不跨缺口、不补零。

canonical case 保存单位、frame、作用对象、版本/identity、参数来源、model level、
assumptions/omissions、四维状态、残差/容差、rank/range/stability、逐刺 geometry/wrench/margins/events。
Parquet trace 对嵌套字段采用带 metadata 的无损 canonical JSON 列编码，公共 reader 可还原空 mapping。

## 9. 仍未闭合的真实输入与边界

真实输入仍缺：钢牌号/强度/疲劳、表面弹性/断裂、完整 cap/cone 尺寸、针管净空/摩擦、
逐刺装配 `d_i0`、三维装配误差、悬架耦合/回差，以及质量、阻尼、动态回弹、损伤演化。

显式模型边界：

- directional status 是当前分支 `q_rate` 耗散与互补残差的准静态单侧代理，不是带质量/阻尼的动态稳定，也未另做有限正向扰动时间积分；
- 任意非比例 mixed-control 的事件中间外载路径未作为完整历史工件保存，solver 保证目标平衡与事件顺序；
- 整爪/整机、背板连续弯曲、杆体分布接触、塑性/磨损/钝化/剥落演化和 CUDA 力学核未实现；
- 本轮只运行解析小 catalog，没有运行 300 地形或正式大 campaign。
