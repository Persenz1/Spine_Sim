# 砂纸、红砖与混凝土地形数据缺口及测量要求

日期：2026-07-29
依据：[`01_public_dataset_review.md`](01_public_dataset_review.md) 和
[`public_topography_sources.csv`](../../data/catalog/public_topography_sources.csv)

## 1. 总体判断

| 材料 | 可直接使用的真实外表面高程 | 可覆盖的子类型 | 是否足以形成材料生成模型 |
|---|---|---|---|
| 砂纸 | FEPA P40/P60/P100/P120/P180/P240 各 1 个 Hirox CSV；本轮实际解析 P240 | 仅 P 系列、单 patch、批次/厂家未知 | **不足**；可启动格式、预处理和单样本统计原型 |
| 红砖 | 0 个公开直接文件；500 样本研究需作者申请 | 红陶砖，5 家砖厂、50 块的潜在覆盖 | **不足**；没有本地原始高度或点云 |
| 混凝土 | Zenodo 抛光混凝土 CSV；Mendeley 水泥浆 STL/PLY 均可直接下载，但本轮未下载大型文件 | 抛光混凝土；w/c 0.4 水泥浆薄片浸水/石蜡 | **不足**；不覆盖常见浇筑/模板/抹面/劈裂/风化/暴露骨料外表面 |

当前没有证据支持用一组经验 RMS/相关长度代表任一种材料，也没有证据支持只用 Sa/Ra 或单个分形维数评价真实性。

## 2. 统计量标定能力矩阵

符号：

- `C`：有条件可算，但样本/元数据不足，不能泛化成材料族；
- `N`：当前不能可靠标定；
- `P`：只有论文统计或处理后对象，缺原始高程；
- `R`：需要获取/测量后再判断。

| 特征 | 砂纸公开数据 | 红砖当前数据 | 混凝土当前数据 | 关键限制 |
|---|---:|---:|---:|---|
| 高度分布 | C | N | C/P | 砂纸单 patch；混凝土表面条件偏置 |
| 2D PSD | C | N | C/P | 需先定 ROI、调平、边界和窗口函数 |
| 自相关 | C | N | C/P | 单个狭长视场难估批次置信区间 |
| 坡度 | C | N | C/P | 对横向采样、噪声和滤波高度敏感 |
| 曲率 | C | N | C/P | 比坡度更依赖仪器带宽；垂直分辨率多为 unknown |
| 峰谷形态 | C | R | C/P | 砂纸 P240 有零值边界和整体趋势 |
| 表面孔洞/凹坑 | C | R | C | 2.5D 只保留从上方可见部分 |
| 各向异性 | C | R | C/P | 必须确认原始轴方向，且需多个旋转/patch |
| 磨粒离散结构 | C | N | 不适用 | 高度图无磨粒实例标签；厂家/磨料/涂附方式未知 |
| 骨料离散结构 | 不适用 | 不适用 | C | Zenodo 有 aggregate/void/cement-paste mask，但仅抛光面 |
| 跨批次变异 | N | R | N | 当前直接数据没有足够 batch 元数据 |
| 磨损演化 | N | N | P | 砂纸磨损状态未知；水泥浆是浸泡时序，不是摩擦磨损 |
| M3 挂接/滑移统计 | C | N | C/P | 必须先完成单位/方向/QC 和分辨率收敛 |

## 3. 砂纸

### 3.1 当前可直接使用

- P40、P60、P100、P120、P180、P240 的 Hirox ground-truth CSV；
- 高度单位 µm，横向采样间距 1.08954 µm；
- 每个文件约 1 mm × 9.5–12.2 mm；
- CC BY 4.0，无登录；
- P240 已完成真实文件下载、哈希和端到端解析。

它们可立即用于：

- Hirox CSV 读取回归；
- ROI、调平、边界和缺失值规则研究；
- 单 patch 的高度、PSD、自相关和 M3 接触敏感度；
- 1/2/5/10 µm 重采样收敛实验。

### 3.2 缺失尺度

- 文件横向长度约 10 mm、宽度约 1 mm，难以同时估计更大尺度的铺砂均匀性；
- 仪器垂直分辨率、光学横向分辨能力和滤波带宽未核实；
- 低于 1.08954 µm sampling interval 的磨粒尖端信息不可恢复；
- 与完整爪刺阵列宽度/行距对应的多 patch 拼接数据不足。

### 3.3 缺失材料和制造条件

- P80 ground-truth CSV 未在公共文件清单中找到；
- 没有 CAMI、JIS 或其他标准体系；
- 厂家、磨料种类、基材、开放/封闭涂附、胶结体系和批次未知；
- 没有同一 grit 的多张纸、多批次、多位置重复；
- 没有新砂纸与不同磨损阶段；
- 没有湿度、污染、纤维翘起或载荷压实条件。

不得根据数字接近在 FEPA、CAMI 和 JIS 间换算或共用参数。

### 3.4 缺失元数据

- z 正方向和零值语义；
- 第一行对应物理 y 的哪一侧；
- 仪器物镜、NA、垂直噪声、缺失值/饱和策略；
- 裁剪、拼接、调平和滤波历史；
- 每个 CSV 与具体实物 patch/批次的关联；
- P240 边界零值是无效填充还是有效测量。

### 3.5 必须自行测量

若项目要声称“砂纸材料模型”而非“六个公开 patch 的拟合”，至少需要：

- 每个选定标准/厂家/批次的多个实物和多个位置；
- 新件与项目关心的磨损等级；
- 同一位置的微观和介观视场；
- 可核实的标准体系、磨料、批次和表面方向；
- 与公开 Hirox 数据至少一个交叉仪器/参考样片。

## 4. 红砖

### 4.1 当前可直接使用

公开直接可下载的、带绝对尺度的红砖外表面高程：**0 份**。

可申请的数据：

- Scientific Reports 研究：5 家砖厂、每家 10 块、共 50 块、500 个样本；
- Starrett AV300+ 点数据；
- 论文声明向通讯作者申请。

在收到文件、许可证、单位、sample-to-block 映射和预处理记录前，数量仍按 0 份可用原始数据计算。

### 4.2 缺失尺度

- 缺少能同时覆盖烧结颗粒、开放孔、压纹和宏观翘曲的多尺度配准；
- 论文给的是设备指标，不是每张图的实际 sampling interval/FOV；
- 缺少尖锐边缘和深孔区域的失测率；
- 缺少与当前 5/10 µm M1 网格的收敛证据。

### 4.3 缺失材料和表面条件

- 实心砖/空心砖；
- 挤出面、切割面、烧结外皮、破坏面；
- 不同原料、成型压力、挤出方向和烧成温度；
- 釉面/未釉面、风化、盐析、污染、潮湿；
- 砖正面、侧面和孔壁；
- 生产批次和厂内变异。

### 4.4 缺失元数据

- 原始文件格式、单位、坐标方向和 z 正方向；
- 每个样本的 FOV/spacing/缺失掩码；
- 500 样本如何对应 50 块砖和 5 家砖厂；
- 调平、异常点、孔洞和边界处理；
- 公开许可和再分发条件。

### 4.5 当前统计能力

论文能证明“多砖厂重复测量是必要的”，但论文中的汇总参数不能替代原始高程。当前不能可靠标定高度分布、PSD、自相关、坡度、曲率、峰谷、孔洞、各向异性或离散烧结颗粒结构。

### 4.6 必须自行测量

如果作者数据不能提供原始文件或缺少关键 metadata，项目必须自测：

- 项目实际接触的砖面；
- 多砖厂/批次；
- 沿挤出方向和垂直方向的配对视场；
- 包含平坦烧结区、开放孔和典型缺陷的分层抽样；
- 对深孔失测区域保存原始质量图/valid mask。

## 5. 混凝土

### 5.1 当前可直接访问

1. Zenodo `18457948`：
   - 抛光混凝土；
   - CLSM RGB + CSV height mappings；
   - void/aggregate/cement-paste masks；
   - 0.69 µm/pixel 的 240x 子集；
   - CC BY 4.0；
   - 当前版本约 8.8 GB。
2. Mendeley `28hj2jdy6r.1`：
   - w/c 0.4 水泥浆薄片；
   - 水/石蜡浸泡时序；
   - Olympus 3D laser confocal；
   - raw/trimmed STL 和 PLY；
   - CC BY 4.0。

二者都能支持管线或特定子类研究，但都不能代表“普通混凝土表面”。

### 5.2 缺失尺度

- 抛光 CLSM 有微观分辨率，但缺少模板纹理、砂浆波纹和粗骨料起伏的厘米级视场；
- 水泥浆 mesh 不含普通混凝土骨料结构；
- 没有将 µm 级水泥浆、mm 级砂粒/孔洞和 cm 级骨料/施工纹理配准的公开集合；
- 大型 Zenodo 文件尚未做文件级高度单位和缺失值验证。

### 5.3 缺失材料和表面条件

- 模板浇筑面（钢模、木模、塑料膜）；
- 抹面、拉毛、喷射、凿毛、磨削；
- 劈裂/断裂面；
- 暴露骨料；
- 普通/高强/纤维/轻骨料混凝土；
- 不同水胶比、骨料级配、养护和龄期；
- 碳化、冻融、磨损、风化、潮湿和污染；
- 建筑墙面实际朝向与施工批次。

### 5.4 缺失元数据

- CSV 高度单位、z 正方向、FOV 和垂直分辨率；
- 每张图的 concrete mix、龄期、抛光步骤和 sample ID；
- mesh/PLY 坐标单位及 Meshmixer 操作；
- 原始采集失败与缺失区域 mask；
- 表面条件与 M3 接触方向。

### 5.5 当前统计能力

- 抛光 CLSM 数据在文件级验证后，有望标定高度、PSD、自相关、坡度、曲率、峰谷和材料分区；
- segmentation mask 可研究气孔/骨料离散结构，但抛光会改变外露表面形貌；
- 水泥浆 STL/PLY 可研究特定浸泡时序，不代表骨料混凝土；
- 缺少普通外露混凝土的跨尺度、跨批次数据，不能构建通用模型。

### 5.6 必须自行测量

项目应优先测量 M3 实际接触的表面处理，而不是抽象的“混凝土”：

- 至少区分模板面、抹面/拉毛面和暴露骨料/风化面；
- 保存 mix、骨料粒径、龄期、养护、含水和处理方式；
- 微观高度与厘米级宏观形貌配准；
- 同一 specimen 多位置、同一条件多 specimen、多批次；
- 同时保存强度/反射强度/质量图，识别孔洞和光学失测。

## 6. 建议测量层级

以下是测量设计层级，不是材料参数。具体 FOV、采样和样本量要由刺尖半径、M3 收敛和目标变异度确定。

### Tier 0：仪器和单位校准

- 可追溯阶高/粗糙度标准；
- 每次批次记录校准日期、物镜、NA、横向 sampling interval、垂直噪声/分辨率；
- 同一参考样片跨仪器测量；
- 保存原始数据和质量/强度图；
- 不把像素间距称作光学分辨率。

### Tier 1：微观接触尺度

目标：尖峰、磨粒顶端、水泥浆微纹理、小孔边缘。

候选仪器：

- coherence scanning interferometry；
- confocal laser scanning microscopy；
- 必要时使用适合陡坡的 focus variation，并报告无法测量的坡度范围。

采样设计应满足：

- 横向 sampling interval 相对最小刺尖半径足够小；
- 垂直噪声显著小于要比较的峰谷/球头包络差；
- 用多分辨率 M3 结果验证，而不是仅按图像清晰度决定。

### Tier 2：介观结构尺度

目标：砂纸铺砂不均匀、砖孔口/烧结颗粒、砂浆孔洞和细骨料。

候选仪器：

- 大视场共焦/focus variation；
- 拼接光学轮廓仪；
- 具有明确绝对尺度和质量 mask 的结构光/激光轮廓仪。

要求：

- 与 Tier 1 重叠并配准；
- 保留拼接误差和每 tile 调平记录；
- 不从普通照片推断绝对微米高程。

### Tier 3：宏观施工/材料尺度

目标：砖面翘曲、模板纹、墙面波纹、粗骨料和阵列跨距变化。

候选仪器：

- 校准的宏观 3D 扫描、结构光或激光轮廓；
- 与 Tier 2 的重叠标记和同一全局坐标。

输出先形成独立尺度证据，是否叠加成多尺度地形必须通过频带和 M3 统计验证，不能简单相加噪声。

## 7. 采集和预处理最低要求

每张/每块数据必须记录：

- material family/subclass；
- 标准体系，砂纸必须明确 FEPA/CAMI/JIS；
- manufacturer、batch、specimen、patch；
- surface finish、方向、condition/wear；
- instrument、objective、sampling interval、分辨/噪声指标；
- FOV、shape、coordinate/height unit；
- x/y 行列方向、z 正方向、表面法向；
- 原始缺失值、饱和、失焦和有效 mask；
- 原始文件哈希、许可证和访问记录；
- ROI、裁边、调平、去趋势、滤波、填补和重采样的全部参数；
- 原始、标准化和用于统计的数据必须是不同对象和不同哈希。

真实性验收至少同时比较：

- 高度分布及尾部；
- 2D PSD 与方向性；
- 自相关；
- 坡度和曲率分布；
- 峰高、峰间距、谷深/谷面积；
- 孔洞/磨粒/骨料的离散结构；
- 多尺度和多 patch 变异；
- 最终的 M3 挂接、滑移、承载和失效统计。

Ra/Sa 或单一分形维数只能是其中一项。

## 8. `decision_required`

项目负责人必须确认：

1. M3 正式研究的刺尖半径范围、阵列跨距和允许的 terrain resolution；当前 10 µm 是否可接受必须由接触统计收敛决定。
2. 砂纸要覆盖哪些标准体系、grit、厂家、批次和磨损状态；不得自动跨 FEPA/CAMI/JIS。
3. 红砖的目标接触面：挤出面、切割面、烧结外皮、破坏面或孔壁中的哪些。
4. 混凝土的目标接触面：模板面、抹面、拉毛、劈裂、暴露骨料、风化面中的哪些。
5. P240 的零值边界是 invalid 还是合法零点，以及允许的 ROI/裁边规则。
6. 调平/去趋势是去除安装姿态还是去除真实宏观形貌；需要给出与物理尺度相关的截止规则。
7. 是否允许使用 CC BY-NC 3.0 的 Micro-Topo 数据；这取决于项目用途。
8. 作者申请数据能否在项目内保存、衍生和共享，必须以作者提供的条款为准。
9. 每个材料子类需要的批次/样本/patch 数和留出验证比例。
10. M3 并行修改何时形成一个可冻结的 M1→M3 接口基线。

已确认、无需再决策：

- 隐藏空洞、倒扣和封闭孔腔不属于当前要求；
- 成品继续采用单值二维高度场；
- M1 只改变来源/生成方式，不改变 M3 当前消费的二维区域和 `TrackGeometry` 语义。
