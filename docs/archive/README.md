# 历史输入与旧仿真证据

本目录只归档曾经驱动工程或支撑旧结果解释的文档，不归档旧源码，也不形成需要
维护的旧版程序。当前物理规范入口是 [`../theory/README.md`](../theory/README.md)；从本目录
提炼并继续生效的装置/加载输入见
[`../engineering/工程仿真参数继承表.md`](../engineering/工程仿真参数继承表.md)，不得直接把
整份旧需求重新提升为规范。

## 目录内容

- `legacy_requirements/`：原 `docs/guide/` 的三份早期工程背景和 M0/M1 执行需求；
- `legacy_simulation_evidence/`：15 份最小旧仿真证据，包括两份主叙事、五份审计、
  两份数据契约和六份运行/选择/完整性 manifest；完整校验清单见该目录的
  `SHA256SUMS.txt`。

旧报告的原始来源为
`D:\Pdrive\Document\论文\爪刺啮合仿真数据及报告`。仓库只保存工程设计需要的
15 份文本与 manifest；报告图片、批量派生表和约 1.2 GB 原始响应数据继续由该目录
管理，不在仓库复制。两份主叙事与源文件的 SHA-256 分别为：

```text
M3_共同背板微刺阵列机理与仿真母稿.md
2690AFB77D7DE8A0CBCC224938004BDC77769E64CD5428F9FB5B11F70152F64A

仿真—理论—既有文献对比报告.md
2804C612399968563A12DF612A76BDEFC2D5F18212C871B139AA10A58905568A
```

这些材料只用于回答“旧程序曾经发现了什么、哪些指标值得保留、哪些结论必须重算”。
凡与新版机理冲突的公式、状态或求解语义均应在唯一生产实现中替换，不能以兼容旧版
为由保留第二条计算路径。

使用这些证据时还必须保留六个边界：地形为未充分标定的合成代理；300 个正式地形的
高度矩阵不在本机；早期派生表曾把无效站点填零，而最终报告采用 missing 与 A 级完整
路径；刚性阵列逐刺反力不唯一；大阵列只有聚合记录；精确源码提交和环境锁未随数据
归档。因此旧结果适合作为语义、守恒、量级和配对趋势回归，不是新版逐点数值真值。
