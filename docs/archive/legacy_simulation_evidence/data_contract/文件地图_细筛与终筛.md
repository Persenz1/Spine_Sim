# M3仿真归档文件地图：细筛与终筛

## 1. 使用目的

本文件用于后续讨论两篇论文的通用分析报告、论文图表和数据追溯。

必须始终区分：

- **细筛**：96个构型、150个地形条件、3档预载，共43,200个case；
- **终筛**：从细筛提出的12个构型、300个地形条件、3档预载，共10,800个case；
- `Terminal Plan`和`终筛12构型方案.csv`是**细筛产生的终筛输入方案**，不是终筛计算结果；
- 文件名以`terminal_`开头或位于`02_派生数据/终筛`、`terminal_scan_12`中的内容，才属于终筛结果。

归档根目录：

```text
M3_独立阵列细筛_20260730_v1/
```

## 3. 说明与口径

### `00_说明与索引/README.md`

归档总说明和快速入口，记录：

- 细筛与终筛规模；
- 终筛严格0.5 mm窗口口径；
- 原始数据不可改写约定；
- 地形母库位置和追溯方式。

### `00_说明与索引/派生指标字段说明.md`

核心指标定义：

- `force_x_N > 0`：阻碍`+x`拖拽，为正向抗拖承载；
- 主阈值：`Fx/preload >= 0.25`；
- `onsetXX_mm`：第一次单点越阈距离；
- `establishXX_mm`：第一次进入稳定承载窗口的距离；
- `duty25`：全路径承载占空比；
- `positive_force_ratio_mean_clipped2`：截顶后的稳健正向累计承载；
- `net_force_ratio_mean`：保留负向区段的净承载；
- `bearing_neff_fraction_median`：承载状态下有效分载比例；
- `bearing_max_load_share_median`：最大单针载荷份额；
- 支撑缺口、再压合、失载恢复和路径尾部低载指标。

## 4. 细筛数据

### 4.1 细筛规模和离散

```text
构型：96
地形条件：150
预载：0.5、1.0、2.0 N
case：96 × 150 × 3 = 43,200
拖拽路径：0–10 mm
步长：0.1 mm
每case：101个空间站
稳定0.5 mm窗口：6个站点中至少5个满足Fx/P >= 0.25
```

### 4.2 细筛原始数据

根目录：

```text
01_原始数据/full_scan/fine/
```

主要文件：

| 路径 | 内容 |
|---|---|
| `manifest.json` | 细筛运行配置、规模、状态和耗时 |
| `ranking.parquet` | 96构型的原始筛选/排名字段 |
| `selected_designs.json` | 原流程选出的构型 |
| `terrain_table.parquet` | 150个地形条件、seed、材料层、源路径和哈希 |
| `complete/*.json` | 每个地形分片的完成标记，共150份 |
| `summaries/*.parquet` | 每个地形分片的case摘要，共150份；每份288个case |
| `paths/*.npz` | 每个地形分片的完整阵列和逐针路径，共150份 |

单个细筛NPZ的主要数组结构：

```text
path_x_m                         (101,)
case_id/design_id/preload_N      (288,)
accepted/station_status          (288, 101)
force_x_N/force_z_N              (288, 101)
neff/max_load_share              (288, 101)
recontacted/contact_count        (288, 101)
spine_mode                       (288, 101, 36)
spine_force_x_N                  (288, 101, 36)
spine_force_z_N                  (288, 101, 36)
spine_lambda_n_N                 (288, 101, 36)
spine_tangent_force_N            (288, 101, 36)
spine_spring_load_N              (288, 101, 36)
spine_spring_displacement_m      (288, 101, 36)
```

第三维统一按最多36根针保存，实际针数由`spine_count`确定。

## 6. 先期报告

### 6.1 细筛报告

```text
03_报告/M3_独立阵列细筛_承载建立与构型筛选报告_v1.md
```

主要任务：

- 重建正向承载、稳定起载、维持、恢复和累计承载定义；
- 说明刚性阵列不能因“出现过一次缺口”直接淘汰；
- 分析刚度、角度、阵列形状、间距、杆径、针尖、地形和预载；
- 提出12构型终筛方案；
- 给两篇论文提出初步数据分工。

关键结论：

- 刚性阵列：稳定起载较快、正向和净承载较高，但载荷集中且有间歇缺口；
- 2000 N/m：细筛总体稳定起载成功率最高，且基本无缺口；
- 300 N/m：均载较好，但全路径净承载可能为负；
- 刚度三联和2×5/5×2方向对照应作为机理证据保留。

### 6.2 终筛报告

```text
03_报告/M3_12构型终筛分析报告_v1.md
```

主要任务：

- 使用终筛0.05 mm步长下的严格0.5 mm窗口；
- 比较12构型的起载、承载幅值、占空比、均载、缺口和恢复；
- 对同一地形做配对比较和成簇bootstrap；
- 给出工程候选和机理对照的分层保留建议。

关键结论：

- A1：严格稳定起载成功率最高、起载较快；
- A2：稳健正向承载和净承载最高；
- A3：无支撑缺口的高刚度柔顺连续接触基线；
- A4：低刚度、高均载，但净承载为负，作为柔顺机制边界；
- A5：紧凑柔顺候选，净承载略正；
- K300/K800/K2000必须成组三联保留；
- D2×5/D5×2必须成对保留；
- 方向对照差异很小，刚度三联显示刚度提高伴随净承载增加和载荷共享下降。

## 9. 当前图片的初步问题

现有图片可用于分析讨论，但尚未按两篇论文的最终叙事定稿。

主要问题：

1. 图片为英文，报告主体为中文，语言和符号体系尚未统一；
2. 细筛图1和图1b的分位带重叠较重，负向长尾压缩了中位曲线；
3. 细筛96构型散点图缺少重点构型标注和清晰的气泡尺寸说明；
4. 终筛六联柱图信息完整，但缺少不确定性/置信区间，横向比较负担较大；
5. 终筛权衡图适合展示Pareto关系，但需补充气泡大小图例和构型代码释义；
6. 跨地形逐距离中位曲线较平，不能充分展示单个case的起载、失载、再压合和恢复过程；
7. 已计算的配对bootstrap置信区间尚未充分进入图片；
8. 尚缺少逐针载荷分担、典型地形过程、失载—恢复和地形分层等机理图。

## 13. 后续讨论的默认规则

- 每次先声明讨论的是**细筛**还是**终筛**；
- 每张图必须标明数据源文件；
- 不把101或201个空间站当作独立统计样本；
- 地形ID是配对和bootstrap的基本单位；
- 未接受站点按零承载处理，同时单独报告缺口；
- 细筛使用5/6站点的0.5 mm窗口；
- 终筛使用10/11站点的0.5 mm窗口；
- 终筛0.25 mm短窗口只用于灵敏度分析；
- 所有图片保留Fx正负方向，不用绝对值掩盖方向反转；
- 原始数据只读，新指标和新图片写入派生数据、图表或新版本目录。
