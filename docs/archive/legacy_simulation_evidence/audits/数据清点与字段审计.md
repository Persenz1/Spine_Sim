# 数据清点与字段审计

## 结论

本轮实际读取粗筛 181,440 case 的
1,344 行设计摘要、43,200 条 96 构型细筛 case、
10,800 条 12 构型终筛 case，以及 180 条大阵列
补测记录。细筛、终筛和大阵列的 A 级完整 case 分别为
35,670、7,410、98；粗筛没有逐路径归档，不能套用相同 A/B/C
重分类。

| 数据源 | 实际记录 | A级完整 | 预载 | 字段范围 |
| --- | --- | --- | --- | --- |
| 1344 构型粗筛 | 181440 | 路径级 A/B/C 不可重算 | 0.5/1/2 N | 1,344 行设计摘要；粗筛无逐站点路径 |
| 96 构型细筛 | 43200 | 35670 | 0.5/1/2 N | 逐站点阵列汇总；无完整逐针切向分量 |
| 12 构型终筛 | 10800 | 7410 | 0.5/1/2 N | 逐站点及逐针 Fx/Fz、状态、残差均可读 |
| 20/40/60 大阵列补测 | 180 | 98 | 2/5/10 N | 仅路径聚合；2 N 为跨数据集锚点 |

## 两套预载设计的关系

- 小阵列细筛/终筛使用 **0.5、1、2 N**，回答低预载下的构型与柔顺机制。
- 大阵列补测使用 **2、5、10 N**，回答阵列规模增大时的预载补偿。
- **2 N 是两套数据有意保留的覆盖锚点**。跨数据集只在 2 N 做定性一致性核对；
  不能把 0.5/1/2 N 与 2/5/10 N 合并成一个未经控制的预载总体。

## 字段字典与正号

| 字段/派生量 | 本轮定义 | 单位 | 审计结论 |
|---|---|---|---|
| `force_x_N` | 阵列抵抗 +x 拖动的幅值，正值为抗拖 | N | 与提示词正号一致 |
| `spine_force_x_N` | 墙面对针的 x 分量；抗拖时通常为负 | N | 逐针 t+ 权重使用 `max(-spine_force_x_N,0)` |
| `force_z_N` / `spine_force_z_N` | 墙面对阵列/逐针的正法向支撑 | N | 逐针和与阵列值一致 |
| `accepted & station_status==0` | 已接受、收敛的站点 | 布尔 | 才允许进入路径积分 |
| `station_status` 1/2/4 | 接口缺口、地形越界或预载不可达 | 类别 | 记缺失，不记物理零 |
| `station_status` 3 | 数值未收敛 | 类别 | 记缺失，单独统计 |
| 有效物理零 | 已接受站点且 `abs(force_x_N)<=1e-12` | N | 与失败状态分离 |
| `neff` / `max_load_share` | 归档的正法向分载指标 | 针数/比例 | 不能泛称综合承载共享 |
| `N_eff^(t+)` | 正向抗拖逐针份额的逆 Herfindahl 数 | 针数 | 仅终筛逐针数据可重算 |

## 状态重分类

本轮没有沿用旧脚本中 `accepted=false → force=0` 的处理。A 级主统计要求完整路径；
B 级部分路径与 C 级零覆盖/失败路径只进入完整性、选择偏差和求解器边界分析。
大阵列 `manifest.json` 中的 `completed_case_count=180` 表示 180 个任务均产生记录，
不是 180 条完整路径。

## 数据版本与缺项

- 终筛的 300 个原始地形矩阵未复制到当前包；路径 NPZ 已保存响应、逐针力与状态，
  足以重算本轮终筛指标，但不能重画那 300 个地形的形貌。本轮地形形貌补充图与
  sigma_g 只使用大阵列补测包中现存的 10 个有限针尖包络地形，并明确标注来源。
- 大阵列根目录仅有 `cases.csv/parquet`、分片 JSON 和地形包络，未发现逐站点/
  逐针大阵列路径。因此不能重算大阵列 J+/J−/Jnet、累计建立概率、
  限制平均建立行程、N_eff^(t+)、逐针热图或路径位置残差。
- 大阵列 manifest 声明的 `report.md` 在数据根目录缺失；本轮不据此补造原报告。
- 小阵列归档求解语义为 `constant-preload-reseat-v3`，不同于“初始预载后固定法向
  位姿”的推荐工程基线；正文结论均限定在该边界内。
- 当前归档无完整 Fy、逐针力矩、阵列合矩或压力中心，故不能声称完成六维 wrench 审计。

完整的逐 cell 数量见 `../tables/数据完整性矩阵.csv`，全部排除记录见
`数值状态与排除清单.csv`。
