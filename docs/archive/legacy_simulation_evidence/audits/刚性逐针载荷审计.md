# 刚性逐针载荷审计

## 审计结论

**部分通过。** 数值合力守恒与归档 Neff 重算在 1e-5 容差下通过；但归档 m3_fast 的刚性反力分配源码/规则未随数据保存，而完全刚性粘着反力在理论上可能非唯一，因此物理唯一性审计不通过。刚性逐针 Neff 只能作为求解器选定分配下的诊断量。

## 解释边界

逐针力求和与阵列合力一致只能说明数值记账自洽，不能证明刚性逐针反力分配是唯一的
物理解。因而本轮不绘制刚性“物理载荷热图”；核心图 6 只展示可审计的柔顺 A3/A4，
刚性 Neff 只作为求解器选定分配下的集中度诊断。

逐 case 数值见 `刚性逐针载荷审计明细.csv`。
