# 降阶接触模型

本模块对应 `src/spine_sim/balanced_contact.py` 中的 `EnvelopeSurface` 与 `CondensedArray`，用于共同刚性背板上针阵列的预载和拖动计算。它与[空间杆接触模型](空间杆接触模型.md)、[六自由度事件阵列模型](阵列模块.md)是独立求解分支。

## 1. 自由度与模型选择

背板转角固定，X 为给定拖动坐标，默认联立求解 Y、Z 与每根针的三个接触力分量，满足

\[
\sum_i f_{iy}=0,\qquad \sum_i f_{iz}=P.
\]

其中 \(\mathbf f_i\) 为表面对针的作用力，抗拖力为 \(T=-\sum_i f_{ix}\)。逐针竖向分力不等于局部法向力，也不必等于 \(P/n\)。

`CondensedArray(..., rigid=False)` 的类默认值为弹性针。运行脚本 `scripts/run_ijms_balanced_contact.py` 的 `--needle-model auto` 按配置中的安装类型选择针模型；刚性／弹性选择由调用端传入，不由类根据安装类型自动推断。`scripts/ijms_confirmation.py` 显式采用 `rigid=True`。

刚性针保留轴向回缩与弹簧，不含针杆弯曲；弹性针采用当前露出长度下的小转角端力—端矩柔度。固定安装的轴向位移为零，弹性柔度可保留。两种分支均不计算完整杆体碰撞、球尖帽域、材料破坏或动态重排。

## 2. 表面与间隙

`EnvelopeSurface` 接收已构造的球尖有效高度场，以 `RectBivariateSpline` 插值高度及两个方向的导数。设有效高度为 \(H(x,y)\)，查询法向为

\[
\mathbf n=\frac{(-H_x,-H_y,1)}{\sqrt{1+H_x^2+H_y^2}}.
\]

插值域外查询抛出 `SURFACE_DOMAIN_LIMIT`。包络网格、生成方法和平滑尺度由输入准备过程决定，不是 `EnvelopeSurface` 的固定参数。

对于球心 \(\mathbf c_i\) 和球尖半径 \(r_i\)，求解器采用局部法向投影间隙

\[
g_i=[c_{iz}-r_i-H(c_{ix},c_{iy})]n_{iz}.
\]

它是有效包络上的局部近似，不是球面到原始三角网格的精确欧氏距离，也不分辨同一球尖的多个独立支撑点。

## 3. 弹簧、柔度与行程

针轴 \(\mathbf a_i\) 从导口指向针尖，轴向接触力为 \(f_{a,i}=\mathbf f_i\cdot\mathbf a_i\)。弹簧安装的压缩量为

\[
s_i=\min(-f_{a,i}/k_i,s_{\max,i}),\qquad l_i=l_{0,i}-s_i.
\]

只有 \(s_{\max,i}<l_{0,i}\) 时，求解器才将该行程上限作为可承载的压缩止挡。止挡反力为

\[
R_{\mathrm{stop},i}=\max(0,-f_{a,i}-k_i s_i),
\]

卸载后允许脱离止挡。若名义行程达到或超过无载露出长度，则完全缩回按几何范围处理，不建立额外止挡。固定安装取 \(s_i=0\)，不使用上述弹簧反力关系。

求解器不将负压缩量截为零，因而不隐含防拔肩。路径控制在 \(s_i<-10^{-6}\,\mathrm m\) 时报告 `AXIAL_EXTENSION_UNSUPPORTED`，在 \(s_i\ge l_{0,i}\) 时报告 `EXPOSED_LENGTH_LIMIT`。前者包含数值范围阈值，不表示物理上允许弹簧承拉。

弹性分支对变截面 \(EI(u)\) 预计算三个柔度积分，在露出长度方向插值，并同时考虑横向端力与球面力臂矩 \(-r_i\mathbf n_i\times\mathbf f_i\)。弯曲导致的端部转动参与接触材料点运动。轴向关系不含弹性配置力，不能视为空间杆能量方程的完全等价降阶。

弹性分支先用前态法向计算变形，再用查询法向作一次端矩—变形更新；它不在单次残差计算内部对该更新无限迭代。

## 4. 接触与摩擦

法向力为 \(N_i=\mathbf f_i\cdot\mathbf n_i\)，切向力为 \(\mathbf f_{t,i}=\mathbf f_i-N_i\mathbf n_i\)。法向残差表达互补条件 \(N_i\ge0\)、\(g_i\ge0\)、\(N_i g_i=0\)。

相对于前一接受态，接触材料点的切向增量近似为

\[
\Delta\mathbf u_i=\Pi_{t,i}\left[\mathbf c_i-\mathbf c_i^{\mathrm{prev}}+
(\boldsymbol\omega_i-\boldsymbol\omega_i^{\mathrm{prev}})\times(-r_i\mathbf n_i)\right].
\]

摩擦系数使用增量尺度的平滑过渡：

\[
\mu_i=\mu_k+(\mu_s-\mu_k)
\exp\!\left[-\frac{\|\Delta\mathbf u_i\|^2}{\ell_\mu^2}\right].
\]

类默认参数为 \(\mu_s=0.5\)、\(\mu_k=0.4\)、\(\ell_\mu=1\,\mu\mathrm m\)，调用端可覆盖。零增量时保留静摩擦圆盘，增量增大时趋近动摩擦系数。该关系不是速度摩擦律；改变路径步长也可能改变增量摩擦过渡。它不同于空间杆分支按粘滑历史切换静／动摩擦系数的实现。

切向残差将 \(\mathbf f_t-(F_0/L_0)\Delta\mathbf u\) 投影到半径 \(\mu\max(N,0)\) 的圆盘，其中 \(F_0=P/n\)、\(L_0=10^{-5}\,\mathrm m\)。接受条件是全部归一化残差的最大绝对值不超过指定容差。残差合格与轴向物理范围检查分别执行。

## 5. 固定坐标的局部求解

`solve(x, preload, previous, ..., fixed_y=None, fixed_z=None)` 可对单个增量施加固定 Y 或 Z 条件。

| 参数 | 替换的方程 | 力的含义 |
|---|---|---|
| 不固定 | \(\sum f_y=0,\ \sum f_z=P\) | 横向自由、恒总预载 |
| `fixed_y` | \(Y=Y_{\mathrm{fixed}}\) | 横向合力成为约束反力 |
| `fixed_z` | \(Z=Z_{\mathrm{fixed}}\) | 竖向合力不再强制等于输入 P |
| 两者均固定 | 两个坐标约束 | 横向与竖向合力均由接触解给出 |

固定 Z 时，`preload` 仍用于残差缩放与初值，`requested_preload_N` 也仍记录该输入；实际载荷须由求解得到的 \(\sum f_{iz}\) 读取。`run()` 默认路径未提供固定坐标参数，此接口用于局部边界对照，不能描述成已实现任意混合控制的完整路径。

固定坐标与 `recover=True` 不可组合，程序会显式拒绝。`scripts/run_ijms_local_feedback.py` 以同一前态分别求解自由 Y/Z、固定 Y/Z、固定 Y 及固定 Z 的局部增量。

## 6. 路径延续、恢复与落点

`run()` 从零力初始状态递增预载，再沿 +X 拖动，继承前一接受态的力、球心、转动和法向。默认拖动步长为 25 μm；失败时缩步，成功后可增回名义步长，终点按剩余距离处理。

普通延续失败后，恢复过程可依次尝试 LSMR 线性子问题、耗散能量提供的初值及邻近横向平衡初值；候选仍须通过原接触与力平衡残差。能量初值或邻近平衡得到的状态标为 `reconfigured`，其生成方式记入 `recovery_method`。横向增量超过两倍名义步长时，记录 `unresolved_rearrangement`；该标志不代表重排瞬态已解析。

路径结果使用 `BALANCED_COMPLETE`、`BALANCED_NUMERICAL_FAILURE`、`BALANCED_AXIAL_RANGE` 和 `BALANCED_BUDGET_LIMIT` 等状态。`checkpoint` 保存最后接受态。`run(resume=...)` 仅允许拖动阶段的数值／预算停止续算，另兼容原 `COMPRESSION_STOP_NOT_IMPLEMENTED` 状态；真实伸出或完全缩回边界不能借续算越过。

`placement_retry.run_with_placements` 是外层预载换点工具。它按给定顺序检查名义路径是否在域内，并对预载阶段的数值失败、轴向范围停止或 CPU 预算停止重新建立零力初态。拖动阶段停止不换点。每次尝试及选中的落点分别保存，不能拼接不同落点的路径。

## 7. 接受态记录与输出

基础 `run()` 的每行记录包括：

- `T_N`、`P_N`、`Y_m`、`Z_m`；
- `forces_N`、`loads_N`、`normal_forces_N`、`compressions_m`；
- `compression_stop_reactions_N`；
- 残差、力平衡误差、穿透量、承载／滑移计数及恢复标志。

`state_observer` 接收初始、恢复、接受、失败或范围停止事件。`scripts/ijms_confirmation.py` 的 `Recorder` 直接从接受态复制 `requested_preload_N`、`contact_normals`、`gaps_m`、`tangential_movement_m` 与 `slip_flags`。详细模式另保存 `accepted_state`、查询坐标、高度及事件状态。

这些逐步字段来自记录器，并非所有基础 `run()` 调用均会输出；缺少字段不能通过事后重算冒充原接受态。压缩轨迹由 `scripts/ijms_compact.py` 编解码，其容器与通用 `CaseOutput`／Parquet 存储格式独立。
