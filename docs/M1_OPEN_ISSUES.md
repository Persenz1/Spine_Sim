# M1 未闭合问题与建议

1. 当前 RTX 4060 Ti/CuPy 14.1.1 已通过 CUDA 夹具并生成十工况库。若迁移到
   其他 GPU、CuPy 主版本或 CUDA runtime，仍需重新保存 provider、device 和
   CPU/GPU 重叠容差结果，不能直接沿用本机结论。
2. 杆体检查只是保守的中心线/圆柱低成本净空诊断，不是杆体分布接触。没有
   露出长度和半径时保留 `model_unclosed_rod_collision`，不得翻译成无挂接。
3. 完整球仍是局部针尖代理。M2 必须调用前向球冠门控；锥段、真实过渡圆角和
   损伤不在 M1 首版范围。
4. `defined_geometry` 是项目定义随机场，不代表砖、混凝土或其他真实材料。
   真实高度图必须单独登记源单位、网格、哈希和预处理。
5. 正式 seed 数尚未批准。M1 只留下小 smoke 和一个最大区域演示；应在 M2/M3
   每轮人工决策后增量生成，不预建 50–80 seed。
6. 文档引用的 `04_爪刺仿真器_失败问题总结与重启约束.md` 仍未在仓库提供。
   若后续补入，开始 M2 大规模筛选前需做一次差异审查。
