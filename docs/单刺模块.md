# 单刺模块

## 1. 模块作用

`src/spine_sim/single_spine.py` 计算一根微刺在一个既定接触候选和相对加载位移下的准静态响应。

它统一处理：

- 低阶梁和附加悬架柔顺；
- 三维点接触库仑摩擦；
- 单边轴向弹簧与硬限位；
- 八态物理状态机；
- 步内最早事件定位；
- 轴体、表面和断裂容量；
- 脱离、准静态回弹和再搜索；
- 不可变 trial/commit。

它不负责搜索地形，也不负责多刺共同背板平衡。

## 2. 输入对象

### `SpineGeometry`

- `spine_id`；
- 根部位置；
- 根到尖轴向；
- 针长、针径和尖端半径；
- frame、根部参考点和背板对象标签。

### `SpineMaterial`

必需：

- 针材杨氏模量；
- 泊松比；
- 剪切修正系数。

可选：

- 轴体允许应力；
- 表面杨氏模量、泊松比和允许拉应力；
- 断裂韧度、裂纹尺度、断裂面积和几何因子；
- 表面/断裂拓扑是否存在；
- 轴体失效是否表示灾难性永久断开；
- 逐字段参数来源。

### `FrictionParameters`

保存静、动摩擦系数和来源，要求：

\[
0\le\mu_k\le\mu_s.
\]

### `SuspensionParameters`

- 可选 3×3 附加柔度矩阵，要求对称半正定；
- 可选单边轴向弹簧刚度和行程，二者必须同时存在；
- 可选回弹恢复距离；
- 参数来源。

### `BaseMotion`

- 接触约束相对刺根的三维位移；
- 相对切向速度；
- 载荷参数；
- 本步搜索距离增量。

相对位移是本构加载坐标，不是刺根实际位移。

### `SpineAcceptedState`

上一已提交状态保存：物理状态、HARDSTOP 子模态、弹簧分支、candidate、接触点/法向、弹性/滑移位移、`CandidateCursor | None`、脱离循环、再挂接计数、回弹距离、损伤事件标签、载荷参数、事件序号和 revision。

主求解器直接接收 `geometry.ContactCandidate`。候选字段、法线表示和 continuation cursor 已由几何模块构造并规范化；单刺模块只执行 near-tie、forward-cap、rod clearance 和 candidate valid 等物理门控。

### `SingleSpineTolerances`

分别控制 gap、力、摩擦、弹簧、速度、容量相对误差和事件 fraction。

## 3. 二维解析基线

`solve_wedge_2d` 实现原始机理第 2 章的有符号二维闭式：

\[
N=T\sin\phi+P\cos\phi,
\]

\[
F_\tau=T\cos\phi-P\sin\phi,
\]

\[
m_f=\mu N-|F_\tau|.
\]

它返回法向力、摩擦需求、摩擦裕度、正/反向极限比、自锁状态和 slip 方向。

该函数用于解析核对。生产 `solve_single_spine` 使用三维各向同性 Coulomb 圆锥，不把二维角度公式作为第二套 solver。

## 4. 梁与悬架柔顺

直圆针杆：

\[
A=\frac{\pi d^2}{4},\qquad
I=\frac{\pi d^4}{64},\qquad
G=\frac{E}{2(1+\nu)}.
\]

轴向和横向柔度：

\[
c_a=\frac{L}{EA},
\qquad
c_t=\frac{L^3}{3EI}+\frac{L}{\kappa GA}.
\]

以刺轴单位向量 \(\mathbf e\) 表示：

\[
\mathbf C_b=
c_a\mathbf e\mathbf e^T+
c_t(\mathbf I-\mathbf e\mathbf e^T)+
\mathbf C_{add}.
\]

程序在每个弹簧活动分支上形成组合柔度，再求接触力和固定分支切线。

## 5. 三维接触

### Stick

由组合柔度反解弹性力，投影到候选法向：

\[
F_n=\mathbf F\cdot\mathbf n,
\qquad
\mathbf F_t=\mathbf F-F_n\mathbf n.
\]

要求：

- \(F_n\ge0\)；
- 静摩擦约束：
  \[
  \|\mathbf F_t\|\le\mu_sF_n.
  \]

### Slip

摩擦方向与相对切向速度相反：

\[
\mathbf F=F_n(\mathbf n-\mu_k\hat{\mathbf v}_t).
\]

法向幅值由组合柔度和加载位移求解。切向速度接近零且重新进入静摩擦锥时，允许 `RESTICK`。

## 6. 单边弹簧

`solve_unilateral_spring` 返回：

| 分支 | 条件/含义 |
|---|---|
| `RIGID` | 未配置轴向弹簧 |
| `LOWER_STOP` | 轴向载荷不足以产生正压缩位移 |
| `INTERIOR` | \(u=F_a/k\)，且 \(0<u<u_{max}\) |
| `HARDSTOP` | \(u=u_{max}\)，超出部分由上限位承担 |

接触力会改变轴向载荷，所以主 solver 需要检查“接触解—弹簧分支”是否自洽，而不是只按外载预选分支。

## 7. 主求解流程

入口：

```python
solve_single_spine(...) -> SingleSpineTrial
```

流程：

1. 核对刺 ID，并读取已规范化的 accepted state 和候选；
2. 处理驻留 `FAILED`、`DETACH`、`REBOUND` 和无候选 `SEARCH`；
3. 依据 candidate signed gap 决定继续搜索、拒绝穿透或脱离；
4. 依次检查 near-tie/选定法向、candidate valid、forward-cap 和 rod clearance；
5. 组装梁与悬架柔度；
6. 遍历轴向弹簧分支，在每个分支中求 stick/slip 并检查分支相容；
7. 在上一 accepted motion 和目标 motion 之间定位最早事件；
8. 生成物理事件和 trial 内临时状态；
9. 计算容量、裕度和失效动作；
10. 计算非穿透、法向、摩擦、弹簧和平衡残差；
11. 生成 proposed state；
12. 只有数值收敛且未停在模型边界时，trial 才可提交。

## 8. 状态与事件

主要状态链：

```text
SEARCH
  └─ CONTACT（瞬时 trial 状态）
       ├─ STICK
       └─ SLIP

STICK / SLIP
  ├─ HARDSTOP（内部仍保存 STICK/SLIP 子模态）
  └─ DETACH → REBOUND → SEARCH

确定的灾难性永久断开 → FAILED
```

accepted state 为 `SEARCH` 时，候选穿透、门控失败或法向反力不为正会产生 `CONTACT_REJECT`，保持 `SEARCH` 并推进 cursor；不经过 detach/rebound，也不增加再挂接计数。已有承载接触遇到正间隙、门控失败或非正法向反力时转入 `DETACH`；接触—弹簧活动集无法闭合时则返回不可提交的 `NONCONVERGED`。

回弹由累计搜索距离达到 `rebound_recovery_distance_m` 判断，是准静态恢复搜索资格的规则，不是动力学回弹轨迹。

## 9. 最早事件定位

程序在一个 trial 步内搜索：

- 正常力归零；
- 静摩擦边界；
- HARDSTOP 进入；
- HARDSTOP 释放；
- 已闭合容量模型的失效边界。

事件在 accepted 与目标 motion 之间二分定位，并选择最早事件。求解结果保存实际被评估的 motion，外层不能假定总是到达原目标步末。

## 10. 容量模型

每个 `CapacityAssessment` 保存：

- 名称；
- `model_state`；
- demand/capacity；
- utilization/margin；
- failure object/mode；
- 参数来源。

当前包含：

### 轴体

组合轴向、弯曲、横向剪切和扭转，形成保守 von Mises 应力上界，与 `shaft_allowable_stress_Pa` 比较。

### Hertz 与表面

计算等效模量、接触半径和中心压力。Hertz 当前提供压力诊断；由表面允许拉应力形成的边缘容量才产生确定失效比较。

正式几何候选目前通常没有局部曲率半径，因此仅有针尖半径不足以让真实表面容量自动闭合。

### II 型断裂

\[
\tau_c=\frac{K_{IIc}}
{Y_{II}\sqrt{\pi c_f}},
\qquad
F_c=\tau_cA_f.
\]

只有断裂韧度、裂纹尺度、几何因子、面积和拓扑均有来源时才返回确定容量。

## 11. 失效动作

- `PERMANENT_REMOVE`：只用于参数闭合且明确声明为灾难断开的轴体失效；该刺进入吸收态 `FAILED`，输出力和切线置零；
- `STOP_MODEL_LIMIT`：当前实现用于非灾难性轴体 `elastic_limit_or_yield`、表面 `edge_tension` 和凸起 `mode_ii_fracture` 边界；这些边界之后没有演化律，trial 停止且不可提交。

缺少参数是 `PARAMETER_UNCLOSED`；没有建模该机制是 `OUT_OF_SCOPE`。程序不会用无来源默认值把两者伪装成材料失效。

`damage_history` 只保存已发生事件标签，不是连续损伤变量或退化本构。

## 12. 输出

`SingleSpineResult`：

- 墙面对针、并经静力平衡传给背板的支撑力；
- 根部 `Wrench`；
- 局部 3×3 切线；
- 物理状态、HARDSTOP 子模态、弹簧分支；
- 法向/切向力和弹性/滑移位移；
- model/numerical state；
- margins、capacity assessments 和 residuals；
- events、failure payload；
- 实际 evaluated motion 和 assumptions。

解释力方向时优先使用 `root_wrench.acting_on/exerted_by`，不要只从字段名猜作用对象。

## 13. Trial 与 commit

`SingleSpineTrial` 保存 base revision、proposed state、result 和 `committable`。

`commit_single_spine_trial` 只接受：

- 同一刺 ID；
- base revision 等于当前 accepted revision；
- `committable=True`；
- numerical state 为 `CONVERGED`。

`SpineAcceptedState` 构造时已经排除瞬时 `CONTACT`，commit 不再重复这一状态检查。

失败 trial 不修改 accepted state。

## 14. 当前边界

- 准静态、单点接触、各向同性 Coulomb 摩擦；
- 低阶线弹性梁和柔顺，不含大塑性/疲劳/磨损；
- 不含有限接触斑、接触偶力和多点接触；
- 不含针—管/杆体分布式接触；
- 回弹没有质量、阻尼和时间积分；
- 损伤后几何不更新；
- 缺真实材料、曲率和断裂拓扑时不能给确定容量。

## 15. 对应机理与测试

对应原始机理：

- 第 2 章：二维摩擦啮合解析基线；
- 第 3 章：单刺承载和局部失效；
- 第 5 章：梁、悬架和单边弹簧；
- 第 6 章：滑移、脱离、回弹和再挂接。
